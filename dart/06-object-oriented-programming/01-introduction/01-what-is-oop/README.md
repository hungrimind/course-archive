# What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of “objects”. It is the most popular way of programming in the modern day.

## History of OOP

Before OOP, all programs were built using “Procedural Programming”. Procedural Programming is a way of writing code in a linear fashion, where you execute one task after another. This is what we have been doing so far in the course.

Procedural Programming is how programming started, and it is still used today in some situations. However, as programs started getting larger, it became more and more challenging to manage these large codebases. We have learned how to use Functions to split up our code already, but when programs become millions of lines of code, you need to split it up even more.

In the 1960s, a Norwegian computer scientist, Ole-Johan Dahl, introduced the concept of Object-Oriented Programming. OOP brought a new way of organizing code, which made it easier to manage large codebases.

![Ole-Johan Dahl](../../../assets/1bf16ec2-ole-johan-dahl.png)

It solved many problems that procedural programming could not, and OOP quickly became the dominant way of programming in the industry. Since then, almost every modern programming language has adopted OOP.

## What are Objects?

OOP is based on the concept of “objects”, but what exactly is an object?

Everything is an object. A car is an object. A person is an object. A book is an object. These are all objects in the real world.

All objects have some properties. For example, a car has a color, a person has a name, and a book has a number of pages.

Objects can also have some functionalities. A car can drive, a person can walk, and a book can be read.

This is what OOP is. Similar to how you would break down functionality and properties of real-world objects, you model your code using a similar approach.

## Classes

The way you create these objects in code is by using Classes. A class is a blueprint for an object. It defines the properties and functionalities that an object will have.

For example, you can create a class called “Car” that has the properties “color” and “brand” and the functionality “drive”.

You can then use this class to create as many “Car” objects as you want. Each car object will have the properties and functionalities defined in the class, but the values of the properties can be different. For example, one car can be a red Tesla, and another can be a blue BMW.
