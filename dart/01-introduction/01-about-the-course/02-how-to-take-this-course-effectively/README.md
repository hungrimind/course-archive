# How to Take this Course Effectively

Each lesson is supposed to make you work so that you deeply understand the topic. I know, I'm sorry!

The quiz lessons are straightforward. Try to answer them correctly, but you get unlimited retries until you do.

Here is how I recommend working through the coding lessons:

1. Read the lesson thoroughly.
2. Try the challenge on your own. Run the code to see if you get the desired outcome.
3. If you can't figure it out, click the "Complete" button, and we will show you which tests don't pass with a reason why. Use this to try again.
4. If you still can't figure it out, refer to the Dart documentation and try again.
5. If you still can't figure it out, you can check the solution.
6. If you believe the lesson could be better in any way, let us know on Discord! Just click the `Help` button at the top of each lesson.

This course will be a lot more work than watching videos, but I promise that if you stick with it, you will have the skills necessary to build software with Dart.

Let’s get started.
