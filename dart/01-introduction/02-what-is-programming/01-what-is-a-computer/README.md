# What is a Computer?

We will get to learning Dart soon, but we first need to zoom out. The definition of programming is:

> [!info] Program
>
> *verb*
>
> Provide a computer with instructions for the automatic performance of a task.

The goal of writing programs is to make a computer do something. How do these words that you type make the computer do something? In fact, what even is a computer, and how does it work?

I'm going to nerd out a bit here because this is why I studied Computer Engineering in college and how I got into working with computers in general. 

I could not fathom how electricity could be turned into playing games, calling friends, or browsing the internet.

We won't go too deep, however, since you don't need to know everything to be able to write Dart. 

But a basic understanding goes a long way.

## Quiz

**1. According to the lesson, what is the fundamental definition of programming?**

- A) The process of building the physical parts of a computer.
- B) The study of how electricity can be turned into games and apps.
- C) The act of making computers faster and more efficient.
- D) Providing a computer with instructions to perform a task.

<details>
<summary>Answer</summary>

- D) Providing a computer with instructions to perform a task.

</details>

**2. Based on the definition of programming, what is the relationship between a program you write and the computer?**

- A) The program is a set of instructions that the computer follows.
- B) The computer is a set of instructions that the program follows.
- C) The program is a physical component that you add to the computer.
- D) The computer and the program collaborate to decide what to do.

<details>
<summary>Answer</summary>

- A) The program is a set of instructions that the computer follows.

</details>
