# What is a Boolean?

A boolean is a type of variable that can only have two possible values: `true` or `false`.

```dart
void main() {
  bool dartIsFun = true;
}
```

It is named after George Boole, an English mathematician and logician. He is known for creating Boolean Algebra, which laid the foundation for the information age that we live in today.

Remember how our programs are written in binary? You use Boolean Algebra to accomplish most of what computers can do.

![George Boole](../../../assets/ad2f1eee-Xnapper-2025-10-28-13.43.37.png)

But they can also be used within your programs. Boolean variables are used to represent the result of a logical or comparison operation.

- Is this number even?
- Is this person older than 18?
- Is it raining?
- Is the user logged in?

All of these questions have an answer that is either true or false. And we can store that answer in a boolean variable.

While they are quite simple, Boolean variables are an important type of variable in programming. They play a big role in writing logic and control flow in your application.
