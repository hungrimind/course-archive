# Print Function Debugging

The `print` function is the simplest way to output information in the terminal. This is one of the most frequently used functions because it provides relevant information to the user of the program. 

However, it is also used frequently for **debugging**.

> [!info] Debugging
>
> *Noun*
>
> The process of identifying and removing errors from computer hardware or software.

You are bound to introduce "bugs" (incorrect code) as you write software. Nobody writes perfect software every time. And the `print` function is one of the tools to solve those bugs.

We will be using it extensively in the upcoming lessons to output information to the terminal as we learn more Dart concepts.
