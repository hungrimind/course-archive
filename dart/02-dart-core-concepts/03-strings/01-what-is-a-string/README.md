# What is a String?

A string is a data type in Dart that is used to represent a sequence of characters. These characters can include letters, numbers, symbols, and spaces.

Strings are used to represent text within your application.

```dart
String greeting = "Hello, World!";
```

The above is a string with the value `Hello, World!`.

This might sound confusing, but a string is just a sequence of characters.

```dart
String greeting = "Hello";
```

The above string is a sequence of 5 characters - H, e, l, l, o.

Strings must be surrounded by either double or single quotes: `""` or `''`.

```dart
String greeting = 'This is also a string';
```

You can use either double or single quotes, but whatever you use to start the string, you must use the same to end the string.

## Quiz

**1. What is the primary purpose of the `String` data type in Dart?**

- A) To perform mathematical calculations.
- B) To store a single true or false value.
- C) To represent a sequence of characters, like text.
- D) To create a list of other variables.

<details>
<summary>Answer</summary>

- C) To represent a sequence of characters, like text.

</details>

**2. Which of the following lines of code correctly declares a string variable in Dart?**

- A) String message = 'Hello, Dart!";
- B) message = "Hello, Dart!";
- C) String greeting = 'Hello, Dart!';
- D) String message = Hello, Dart!;

<details>
<summary>Answer</summary>

- C) String greeting = 'Hello, Dart!';

</details>

**3. According to Dart syntax, which type of quotes can you use to define a string?**

- A) Only double quotes (").
- B) Only single quotes (').
- C) Either single (') or double (") quotes, as long as they match.
- D) No quotes are needed.

<details>
<summary>Answer</summary>

- C) Either single (') or double (") quotes, as long as they match.

</details>
