# What is a Variable?

At its core, a variable is a storage container for data.

```dart
var name = "Tadas";
```

The code above creates a variable called `name` with the value `Tadas`. Now, we can use the variable later in our code, and it will have the value of `Tadas`.

```dart
print(name); // Tadas
```

You can store different types of data in a variable. You can even change the value of a variable.

```dart
var name = "Tadas";
print(name); // Tadas

name = "Matt";
print(name); // Matt
```

Variables are a very simple concept, but you will use them everywhere when building your Dart applications. So, you must understand them. We will go into more detail on variables in the next few lessons.
