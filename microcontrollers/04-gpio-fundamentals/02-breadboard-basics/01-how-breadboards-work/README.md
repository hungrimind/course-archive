# How Breadboards Work

A **breadboard** lets you build circuits by pushing wires and components into holes, with no soldering needed. Underneath, metal strips connect groups of holes together.

Each short row (typically 5 holes) is connected internally. Plug an LED leg into one hole and a wire into another hole *in the same row*, and they're electrically linked. The center gap splits the board in two: rows on the left side don't connect to rows on the right. This gap is sized to fit chips that straddle both sides.

## True or False

**1. True or false:** Each short row on a breadboard typically has 5 holes connected internally.

<details>
<summary>Answer</summary>

**True**: Underneath the breadboard, metal strips connect each short row of 5 holes together, so inserting components into the same row links them electrically.

</details>

**2. True or false:** Rows on the left side of the center gap connect to rows on the right side.

<details>
<summary>Answer</summary>

**False**: The center gap splits the board in two: rows on the left don't connect to rows on the right. This gap is sized to fit chips that straddle both sides.

</details>

**3. True or false:** You need to solder components onto a breadboard to make connections.

<details>
<summary>Answer</summary>

**False**: Breadboards are designed for solderless prototyping. You build circuits by pushing wires and components into holes, with no soldering needed.

</details>
