# What Is GPIO?

**GPIO** stands for General Purpose Input/Output: a set of pins on your Pi that your code can control directly. Each pin is a tiny electrical contact that can either send a signal out or listen for one coming in.

Think of GPIO pins as *switches your code can flip*. Write a line of Python, and a pin sends voltage to an LED. Read a pin's state, and you know whether a button is pressed. That's the entire bridge between software and the physical world.

## Quiz

**1. What does GPIO stand for?**

- A) General Peripheral Input/Output
- B) General Purpose Input/Output
- C) Global Pin Input/Output
- D) Ground Power Input/Output

<details>
<summary>Answer</summary>

- B) General Purpose Input/Output

GPIO stands for General Purpose Input/Output: a set of pins on the Pi that your code can control directly to send or receive electrical signals.

</details>

**2. What can a GPIO pin do?**

- A) Only send signals out to components
- B) Only listen for incoming signals
- C) Either send a signal out or listen for one coming in
- D) Process data like a CPU

<details>
<summary>Answer</summary>

- C) Either send a signal out or listen for one coming in

Each GPIO pin can either send a signal out (output) or listen for one coming in (input), acting as the bridge between your code and the physical world.

</details>

**3. Which of the following best describes the role of GPIO pins?**

- A) They store data like RAM
- B) They provide network connectivity
- C) They bridge software and the physical world
- D) They regulate the Pi's internal temperature

<details>
<summary>Answer</summary>

- C) They bridge software and the physical world

GPIO pins are the bridge between software and the physical world: write Python to send voltage to an LED, or read a pin to detect a button press.

</details>
