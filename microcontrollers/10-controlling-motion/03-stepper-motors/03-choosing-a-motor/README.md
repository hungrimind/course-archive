# Choosing a Motor

**Servo** -- pick this when you need a specific angle within a limited range (usually 180 degrees). Great for anything that pivots: robot joints, rudders, pan/tilt mounts.

**DC motor** -- pick this when you need something to spin fast and continuously. Wheels, fans, propellers. Speed is easy to control with PWM, but position is not.

**Stepper** -- pick this when you need precise, continuous rotation. 3D printers and CNC machines use steppers because every step is an exact, repeatable movement with no feedback circuit required.

The question is always: *what kind of motion do you need?*
