# ESP32 Overview

The **ESP32** is a microcontroller with **Wi-Fi and Bluetooth built into the chip**. No extra modules, no shields: wireless connectivity is just there.

This makes it the go-to board for IoT projects: reading a sensor and posting data to the cloud, controlling a motor from your phone, or triggering an alert over the network. It runs MicroPython, costs around $5, and has enough GPIO pins for most projects.

If your project needs to talk to the internet, the ESP32 is probably your board.

## Quiz

**1. What makes the ESP32 especially suited for IoT projects?**

- A) It runs a full desktop operating system
- B) It has Wi-Fi and Bluetooth built directly into the chip
- C) It is the most expensive microcontroller available
- D) It can only be programmed in C++

<details>
<summary>Answer</summary>

- B) It has Wi-Fi and Bluetooth built directly into the chip

The ESP32 has Wi-Fi and Bluetooth built into the chip itself, with no extra modules or shields needed, making it ideal for projects that need wireless connectivity.

</details>

**2. Which programming language can the ESP32 run for hardware projects?**

- A) Java
- B) Swift
- C) MicroPython
- D) Ruby

<details>
<summary>Answer</summary>

- C) MicroPython

The ESP32 runs MicroPython, which lets you write Python code to control hardware. It also has enough GPIO pins for most projects and costs around $5.

</details>

**3. Which scenario is the BEST fit for choosing an ESP32?**

- A) You need a board with a full desktop environment and display
- B) You want to read sensor data and send it to a cloud server over Wi-Fi
- C) You need the largest possible library and community ecosystem
- D) You need a board that runs traditional Arduino C++ only

<details>
<summary>Answer</summary>

- B) You want to read sensor data and send it to a cloud server over Wi-Fi

The ESP32's built-in Wi-Fi makes it the go-to choice for projects that need internet connectivity, such as reading sensors and posting data to the cloud.

</details>
