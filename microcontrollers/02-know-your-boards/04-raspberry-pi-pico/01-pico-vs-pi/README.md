# Pico vs Pi

The **Raspberry Pi Pico** is *not* a tiny Linux computer. It's a true microcontroller: no OS, no desktop, no boot sequence. You plug it in and your code runs instantly, just like an Arduino.

The difference from Arduino is that the Pico runs **MicroPython** natively, so you get Python's friendly syntax on a board that costs $4. It shares the Raspberry Pi name but sits in a completely different category: the Pi is a computer that can do hardware, the Pico is hardware that you program.

## True or False

**1. True or false:** The Raspberry Pi Pico is a smaller version of the Raspberry Pi that runs Linux.

<details>
<summary>Answer</summary>

**False**: Despite sharing the Raspberry Pi name, the Pico is a true microcontroller with no OS, no desktop, and no boot sequence. It is in a completely different category from the Raspberry Pi.

</details>

**2. True or false:** The Pico runs MicroPython natively, giving you Python syntax on a microcontroller.

<details>
<summary>Answer</summary>

**True**: Unlike Arduino which traditionally uses C/C++, the Pico runs MicroPython natively, combining Python's friendly syntax with microcontroller simplicity.

</details>

**3. True or false:** When you plug in a Pico, your code runs instantly without a boot sequence.

<details>
<summary>Answer</summary>

**True**: Like an Arduino, the Pico has no OS to boot. You plug it in and your program runs immediately.

</details>

**4. True or false:** The Raspberry Pi Pico costs significantly more than a full Raspberry Pi.

<details>
<summary>Answer</summary>

**False**: The Pico costs around $4, making it one of the cheapest boards available and far less expensive than a full Raspberry Pi.

</details>
