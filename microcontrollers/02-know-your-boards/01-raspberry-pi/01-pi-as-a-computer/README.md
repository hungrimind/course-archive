# Pi as a Computer

A **Raspberry Pi** is a full Linux computer the size of a credit card. It has USB ports, HDMI output, Wi-Fi, and runs a desktop operating system, so you can browse the web, write code, and watch videos on it.

What makes it special for hardware projects is the row of **GPIO pins** along one edge. These pins let your code talk directly to LEDs, sensors, and motors while you still have a full OS underneath for debugging, networking, and file management.

*Think of it as a laptop that also happens to have bare wires sticking out for you to connect things to.*

## Quiz

**1. What distinguishes a Raspberry Pi from a typical microcontroller?**

- A) It can only run one program at a time in a loop
- B) It runs a full Linux operating system with a desktop environment
- C) It has no USB or HDMI ports
- D) It requires a separate Wi-Fi adapter to connect to the internet

<details>
<summary>Answer</summary>

- B) It runs a full Linux operating system with a desktop environment

A Raspberry Pi is a full Linux computer the size of a credit card, with USB ports, HDMI output, Wi-Fi, and a desktop OS, unlike a basic microcontroller that runs a single program without an operating system.

</details>

**2. What feature allows a Raspberry Pi to interact with physical hardware like LEDs and sensors?**

- A) Its HDMI output port
- B) A special hardware expansion card
- C) Its row of GPIO pins
- D) Its USB ports

<details>
<summary>Answer</summary>

- C) Its row of GPIO pins

The GPIO (General Purpose Input/Output) pins along one edge of the Pi let your code talk directly to LEDs, sensors, and motors, while you still have the full OS for debugging and networking.

</details>

**3. Why is having a full operating system useful when doing hardware projects on a Raspberry Pi?**

- A) It makes the Pi cheaper to manufacture
- B) It provides debugging, networking, and file management alongside hardware control
- C) It eliminates the need for GPIO pins
- D) It ensures the board has no boot time

<details>
<summary>Answer</summary>

- B) It provides debugging, networking, and file management alongside hardware control

A full OS gives you access to debugging tools, networking capabilities, and file management, all of which are helpful when building and troubleshooting hardware projects.

</details>
