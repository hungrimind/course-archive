# What Is Arduino?

An **Arduino** is a microcontroller board with no operating system. It runs a single program in a loop, forever, the moment you power it on. That simplicity is its strength: no boot time, no updates, no crashes from background processes.

Arduino's massive community means almost every sensor or component you can buy comes with an Arduino library and a wiring tutorial. It's the platform that kicked off the maker movement.

> [!tip] Arduino traditionally uses C/C++, but in this course we focus on Python-based boards. The concepts (GPIO, signals, sensors) transfer directly.

## True or False

**1. True or false:** An Arduino runs a full operating system like Linux.

<details>
<summary>Answer</summary>

**False**: Arduino has no operating system. It runs a single program in a loop from the moment it's powered on.

</details>

**2. True or false:** Arduino runs a single program in a loop as soon as it is powered on.

<details>
<summary>Answer</summary>

**True**: That simplicity is one of Arduino's key strengths: no boot time, no updates, and no crashes from background processes.

</details>

**3. True or false:** Arduino's large community means most sensors and components come with libraries and wiring tutorials.

<details>
<summary>Answer</summary>

**True**: Arduino's massive community is a major advantage, providing ready-made libraries and tutorials for almost every sensor or component you can buy.

</details>

**4. True or false:** Arduino traditionally uses Python as its primary programming language.

<details>
<summary>Answer</summary>

**False**: Arduino traditionally uses C/C++. While the concepts like GPIO and signals transfer to Python-based boards, Arduino itself is C/C++ based.

</details>
