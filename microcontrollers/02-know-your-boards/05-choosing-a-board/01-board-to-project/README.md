# Board to Project

Choosing a board comes down to one question: **what does your project need?**

Need a desktop, camera, or display? **Raspberry Pi.** Need Wi-Fi or Bluetooth? **ESP32.** Need the biggest library ecosystem and community support? **Arduino.** Need cheap, simple, and Python-friendly? **Pico.**

Most beginners overthink this. If you're unsure, start with whatever board you already have. The GPIO concepts, wiring patterns, and sensor logic you learn on one board transfer directly to every other board.
