# DHT Sensor Family

The **DHT11** and **DHT22** are small, cheap sensors that measure both temperature and humidity through a single data pin. They look almost identical and wire up the same way.

The difference is precision. The DHT11 reads 0-50 C with ~2 C accuracy, while the **DHT22** handles -40 to 80 C with ~0.5 C accuracy. For a hobby project where "roughly warm" is fine, the DHT11 works. For anything you actually want to trust, use the DHT22.

> [!tip] Both sensors use the exact same code and libraries, so swapping one for the other is a one-line change.
