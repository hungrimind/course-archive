# Code Meets Circuits

A **microcontroller** is a tiny computer that runs your code and connects directly to physical things -- LEDs, motors, sensors, buttons. Unlike a desktop where your program lives behind a screen, microcontroller code *reaches into the real world*.

You already know how to write a loop or an if-statement. The difference here is what happens next: instead of updating a UI, your code sends an electrical signal down a wire and something physical responds.

> [!tip] If you can write a Python script, you can control hardware. The logic is the same -- only the output changes.

## Quiz

**1. What makes microcontroller programming different from typical desktop programming?**

- A) Microcontrollers use a completely different programming language
- B) Your code controls physical things through electrical signals
- C) Microcontrollers cannot use loops or if-statements
- D) Desktop programs are always faster than microcontroller programs

<details>
<summary>Answer</summary>

- B) Your code controls physical things through electrical signals

The key difference is that microcontroller code reaches into the real world -- instead of updating a screen, it sends electrical signals to control physical devices like LEDs, motors, and sensors.

</details>

**2. You write a Python script that turns on a fan when a room gets too warm. Where does this code most likely run?**

- A) A web server
- B) A desktop operating system
- C) A microcontroller
- D) A smartphone app

<details>
<summary>Answer</summary>

- C) A microcontroller

Directly reading a temperature sensor and controlling a fan requires a physical connection to hardware. A microcontroller connects to sensors and motors through its pins, making it the right platform for this task.

</details>

**3. Which of the following is NOT something a microcontroller typically connects to directly?**

- A) An LED
- B) A button
- C) A web browser's DOM
- D) A motor

<details>
<summary>Answer</summary>

- C) A web browser's DOM

A microcontroller connects to physical components like LEDs, buttons, and motors. A web browser's DOM is a software abstraction on a desktop or mobile device, not a physical thing a microcontroller wires to.

</details>
