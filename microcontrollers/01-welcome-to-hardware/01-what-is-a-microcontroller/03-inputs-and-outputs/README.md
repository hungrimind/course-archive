# Inputs and Outputs

Every hardware project follows one pattern: **read inputs, control outputs**.

An **input** is anything the microcontroller listens to -- a button press, a temperature sensor, a light detector. An **output** is anything it controls -- an LED, a motor, a buzzer. Your code sits in the middle, deciding what outputs to change based on what inputs report.

> [!tip] When you look at any hardware project, ask: "What are the inputs and what are the outputs?" Everything else is just the logic connecting them.
