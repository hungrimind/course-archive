# Key-Value Stores

A **Key-Value Store** is a simple database that uses a unique key to quickly access a corresponding value. It's like a dictionary where each key leads directly to its value.

```text
# Example: key-value pairs (JSON)
{
  "theme": "dark",
  "notifications": "enabled"
}
```

Here, `theme` and `notifications` are keys used to retrieve their respective values.

> [!note]
> Use key-value stores for caching, session management, or storing user preferences. They excel at high-speed, simple lookups.
