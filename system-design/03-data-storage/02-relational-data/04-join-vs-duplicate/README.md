# Join vs Duplicate

A **join** is used to combine data from multiple tables based on a related column, reducing redundancy by keeping data normalized. **Duplication**, on the other hand, involves storing identical data in multiple locations, which can simplify queries but increases storage and risks inconsistencies.

> [!note]
> Choose joins to maintain data integrity, but consider duplication for performance when read-heavy access patterns benefit from it.
