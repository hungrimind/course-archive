# Replication vs Sharding

A **replication** is the process of copying data across multiple databases to increase data availability and fault tolerance. Each copy is known as a replica, which can be used for read operations to distribute load.

A **sharding** is dividing a database into smaller, more manageable pieces called shards. Each shard holds a subset of the entire dataset to distribute data and queries, improving scalability.

> [!note]
> Use replication to enhance read performance and availability, while sharding is best for handling large datasets by distributing them.
