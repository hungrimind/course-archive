# Dashboards vs Alerts

A **dashboard** is a visual interface displaying real-time data and metrics about a system's performance and health. **Alerts**, on the other hand, are notifications triggered by specific conditions or threshold breaches within the system.

```plaintext
Dashboard: Shows live CPU usage, memory stats, etc.
Alert: Sends a notification if CPU usage exceeds 80%.
```

> [!note]
> Dashboards provide ongoing insights, while alerts demand immediate attention.
