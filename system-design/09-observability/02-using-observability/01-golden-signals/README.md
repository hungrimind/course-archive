# Golden Signals

A **golden signal** is a key indicator of a system's health and performance. The four primary golden signals are latency, traffic, errors, and saturation.

- **Latency**: Time taken to process a request.
- **Traffic**: System demand, like requests per second.
- **Errors**: Rate of failing requests.
- **Saturation**: Resource utilization, indicating capacity limits.

> [!tip]
> Monitoring these signals helps in quick diagnosis and maintaining system reliability.
