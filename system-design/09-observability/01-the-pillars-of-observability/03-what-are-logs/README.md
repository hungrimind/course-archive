# What are Logs?

A **log** is a record of events or messages generated by a system. Logs capture detailed information about system operations and are crucial for debugging and monitoring.

```plaintext
Example: [2023-11-01 12:30:00] INFO: User login successful
```

> [!note]
> Logs provide context for metrics and help trace specific events when troubleshooting issues.

## Quiz

**1. What is the primary purpose of a log in a system?**

- A) To store system passwords
- B) To capture detailed information about system operations
- C) To act as a user interface
- D) To replace system backups

<details>
<summary>Answer</summary>

- B) To capture detailed information about system operations

Logs capture detailed information about system operations, which aids in debugging and monitoring, making them essential for understanding system behavior.

</details>

**2. Why are logs essential during troubleshooting?**

- A) They provide aesthetic improvements to the system
- B) They automatically resolve issues
- C) They help trace specific events and provide context for issues
- D) They offer real-time user feedback

<details>
<summary>Answer</summary>

- C) They help trace specific events and provide context for issues

Logs help trace specific events and provide essential context, making them invaluable for identifying and resolving issues during troubleshooting.

</details>
