# What are Metrics?

A **metric** is a quantifiable measure used to gauge system performance and behavior. It helps track and understand how well a system is functioning.

```plaintext
Examples: CPU usage, response times, error rates
```

> [!tip]
> Regularly monitoring metrics can help detect anomalies and prevent system failures.

## Quiz

**1. What is the primary purpose of a metric in system management?**

- A) To increase system hardware
- B) To gauge system performance and behavior
- C) To create data backups
- D) To reduce operational costs

<details>
<summary>Answer</summary>

- B) To gauge system performance and behavior

Metrics are primarily used to measure and understand how well a system is functioning by quantifying performance and behavior.

</details>

**2. Which of the following is an example of a metric?**

- A) System design
- B) User interface
- C) Response times
- D) Software updates

<details>
<summary>Answer</summary>

- C) Response times

Response times are a quantifiable measure of how quickly a system responds to inputs, making it a metric.

</details>

**3. Why is it important to monitor metrics regularly?**

- A) To increase team productivity
- B) To gain customer satisfaction
- C) To detect anomalies and prevent system failures
- D) To develop new software features

<details>
<summary>Answer</summary>

- C) To detect anomalies and prevent system failures

Regularly monitoring metrics helps identify deviations from expected performance, thus allowing for early intervention to prevent failures.

</details>
