# HTTP Status Codes

A **HTTP Status Code** is a three-digit number that indicates the result of an HTTP request. It helps clients understand if their request was successful or if an error occurred.

- **2xx**: Success (e.g., 200 OK)
- **4xx**: Client error (e.g., 404 Not Found)
- **5xx**: Server error (e.g., 500 Internal Server Error)

```text
# Example response line with a 200 OK status
HTTP/1.1 200 OK
```

> [!note]
> Status codes help automate error handling and improve user experience by indicating what went wrong.
