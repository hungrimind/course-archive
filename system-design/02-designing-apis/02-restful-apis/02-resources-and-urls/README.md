# Resources and URLs

A **resource** in REST is any object or entity that can be accessed or manipulated through an API. Each resource is identified by a unique **URL** (Uniform Resource Locator), which acts like an address pointing to the resource.

```text
# Example URL pointing to a user resource
GET /users/123
```

In this example, `/users/123` is the URL representing the user with ID 123. URLs should be descriptive and hierarchical, reflecting the structure of your resources.

> [!tip]
> Use nouns in URLs to represent resources, not verbs. For example, use `/users` instead of `/getUsers`.
