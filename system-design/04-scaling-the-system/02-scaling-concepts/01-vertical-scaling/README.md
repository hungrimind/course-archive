# Vertical Scaling

A **vertical scaling** increases a single machine's capacity by adding more resources like CPU, RAM, or storage. This approach enhances performance without altering the application architecture.

> [!note]
> Vertical scaling has limits: there's only so much you can upgrade a single machine before hitting a maximum capacity.

## True or False

**1. True or false:** Vertical scaling involves adding more machines to a system to enhance performance.

<details>
<summary>Answer</summary>

**False**: Vertical scaling focuses on upgrading a single machine's resources, while adding more machines is known as horizontal scaling.

</details>

**2. True or false:** Vertical scaling can be limited by the maximum capacity of a single machine.

<details>
<summary>Answer</summary>

**True**: Vertical scaling can only increase a machine's resources up to its maximum capacity, after which no further enhancements can be made.

</details>

**3. True or false:** Vertical scaling requires significant changes to the application architecture.

<details>
<summary>Answer</summary>

**False**: One of the benefits of vertical scaling is that it improves performance without necessitating changes to the application architecture.

</details>

**4. True or false:** Upgrading CPU and RAM are examples of vertical scaling.

<details>
<summary>Answer</summary>

**True**: Vertical scaling involves increasing a machine's resources, such as its CPU and RAM, to improve its performance.

</details>
