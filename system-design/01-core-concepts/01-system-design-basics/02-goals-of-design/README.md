# Goals of Design

A **goal of design** in system design is to create a system that effectively meets user needs while balancing constraints like performance, scalability, and cost. 

> [!note]
> Design goals often include maintainability, flexibility, and reliability, ensuring the system can evolve and perform well over time.

## True or False

**1. True or false:** System design should focus solely on fulfilling user needs, without considering constraints like cost and performance.

<details>
<summary>Answer</summary>

**False**: While meeting user needs is crucial, system design must also balance constraints such as performance, scalability, and cost to be truly effective.

</details>

**2. True or false:** Flexibility is an important goal in system design because it allows the system to adapt to changing requirements.

<details>
<summary>Answer</summary>

**True**: Flexibility is crucial in system design as it enables the system to incorporate changes and adapt over time, which is essential for long-term success.

</details>

**3. True or false:** Achieving high performance in a system design is more important than maintainability and reliability.

<details>
<summary>Answer</summary>

**False**: Performance is important, but maintainability and reliability are equally crucial, as they ensure the system can perform well and evolve over time without excessive costs or breakdowns.

</details>

**4. True or false:** Scalability in system design refers to the ability of a system to maintain or improve performance as it is expanded to accommodate growth.

<details>
<summary>Answer</summary>

**True**: Scalability ensures a system can handle increasing loads or expanded scope without a decline in performance, making it vital for systems expected to grow.

</details>
