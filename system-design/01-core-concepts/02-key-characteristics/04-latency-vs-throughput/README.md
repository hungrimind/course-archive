# Latency vs Throughput

A system’s **latency** is how long one request takes from start to finish.

A system’s **throughput** is how many requests the system can handle per unit of time (for example, requests/second).

Example:
- Latency: **120 ms** average per request
- Throughput: **1,000 requests/second**

> [!note]
> Real-time apps (chat, gaming) often prioritize **low latency**. Batch systems often prioritize **high throughput**.

Latency is “speed per request.” Throughput is “how much work per second.”
