# TLS Basics

A **Transport Layer Security (TLS)** protocol ensures secure communication over a network by encrypting data transmitted between a client and server. It prevents eavesdropping and tampering.

```plaintext
Client <---TLS---> Server
```

TLS is crucial for protecting sensitive information, such as passwords and credit card numbers, during transmission. 

> [!tip]
> Always use HTTPS, which incorporates TLS, to secure web traffic.

## Quiz

**1. What is the primary purpose of the TLS protocol?**

- A) To compress data for faster transmission
- B) To encrypt data for secure communication
- C) To convert data into XML format
- D) To visualize data traffic

<details>
<summary>Answer</summary>

- B) To encrypt data for secure communication

TLS encrypts data to ensure secure communication between a client and server, preventing eavesdropping and tampering.

</details>

**2. Why is TLS important for transmitting sensitive information such as passwords?**

- A) It increases data transmission speed
- B) It guarantees data integrity
- C) It secures data from unauthorized access
- D) It decreases server load

<details>
<summary>Answer</summary>

- C) It secures data from unauthorized access

TLS is important because it encrypts data, securing sensitive information from unauthorized access during transmission.

</details>

**3. Which statement best describes the relationship between HTTPS and TLS?**

- A) HTTPS is a protocol that does not involve TLS at all
- B) TLS is used by HTTPS to secure web traffic
- C) TLS replaces the need for HTTPS
- D) HTTPS is used to encrypt emails, while TLS is not

<details>
<summary>Answer</summary>

- B) TLS is used by HTTPS to secure web traffic

HTTPS incorporates TLS to ensure that web traffic is securely encrypted and protected from unauthorized access.

</details>
