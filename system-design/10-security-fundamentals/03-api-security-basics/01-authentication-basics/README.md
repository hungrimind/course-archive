# Authentication Basics

**Authentication Basics**

**Authentication** verifies the identity of a user or system before granting access. It ensures that only legitimate users can enter the system.

```plaintext
[Username + Password] -> [Identity Verification]
```

This process typically involves credentials like passwords or tokens, which are checked against stored data to confirm identity. 

> [!tip]
> Strong authentication methods reduce the risk of unauthorized access. Consider multi-factor authentication for added security.

## Quiz

**1. What is the primary purpose of authentication in a system?**

- A) To encrypt data during transmission
- B) To verify a user's identity before granting access
- C) To monitor user activity within the system
- D) To backup user data

<details>
<summary>Answer</summary>

- B) To verify a user's identity before granting access

The primary purpose of authentication is to verify the identity of a user or system to ensure access is granted only to legitimate users.

</details>

**2. Which of the following is a common method used during the authentication process?**

- A) Using a firewall
- B) Biometric scanning
- C) Requesting a username and password
- D) Encrypting files

<details>
<summary>Answer</summary>

- C) Requesting a username and password

Requesting a username and password is a common method for identity verification in authentication processes.

</details>

**3. How does multi-factor authentication enhance security?**

- A) By requiring multiple passwords for login
- B) By ensuring only encrypted data is transmitted
- C) By requiring additional verification steps beyond just passwords
- D) By limiting login attempts to three

<details>
<summary>Answer</summary>

- C) By requiring additional verification steps beyond just passwords

Multi-factor authentication enhances security by requiring additional verification steps, making it harder for unauthorized users to gain access.

</details>
