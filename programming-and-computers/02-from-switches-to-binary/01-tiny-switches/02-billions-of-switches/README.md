# Billions of Switches

A single transistor can only say ON or OFF. Not very useful on its own. But a modern computer chip has *billions* of them, each one smaller than a virus.

By wiring enormous numbers of these simple switches together, engineers create circuits that can add numbers, compare values, and store information. One switch does almost nothing. Billions of them working together can run video games, play music, and send messages around the world.

## True or False

**1. True or false:** A single transistor on its own can add numbers and store information.

<details>
<summary>Answer</summary>

**False**: A single transistor can only say ON or OFF. It takes billions of transistors wired together to create circuits that can add numbers, compare values, and store information.

</details>

**2. True or false:** Modern computer chips contain billions of transistors, each smaller than a virus.

<details>
<summary>Answer</summary>

**True**: Transistors have been shrunk to an incredibly small scale. A modern chip packs billions of them together, and each one is smaller than a biological virus.

</details>

**3. True or false:** Computers need billions of transistors because each individual transistor is very slow.

<details>
<summary>Answer</summary>

**False**: The reason is not speed but capability. A single transistor can only switch ON or OFF. Useful work like adding numbers or running games requires combining enormous numbers of these simple switches into complex circuits.

</details>
