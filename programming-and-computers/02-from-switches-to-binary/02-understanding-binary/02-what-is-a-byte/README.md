# What is a Byte?

A **byte** is a group of 8 bits. It's the standard "chunk" computers use to work with data.

With 8 bits, you get 256 possible values (0 through 255). That's enough to hold a single letter, a small number, or one channel of a color. When people say a file is "500 bytes," they mean it takes 500 groups of 8 bits to store.
