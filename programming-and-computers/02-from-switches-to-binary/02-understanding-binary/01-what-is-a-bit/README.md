# What is a Bit?

A **bit** is a single 1 or 0, the smallest piece of data a computer can store. The word comes from "**b**inary dig**it**."

One bit gives you two possibilities: on/off, yes/no, true/false. That's not much on its own, but you can combine bits to represent more. Two bits give you four possibilities. Three bits give you eight. The more bits you string together, the more values you can express.

## True or False

**1. True or false:** A single bit can represent 10 different values.

<details>
<summary>Answer</summary>

**False**: A single bit can only be 0 or 1, giving it exactly 2 possible values, not 10.

</details>

**2. True or false:** Adding one more bit to a group doubles the number of possible values.

<details>
<summary>Answer</summary>

**True**: Each additional bit doubles the possibilities. 1 bit = 2 values, 2 bits = 4 values, 3 bits = 8 values, and so on.

</details>

**3. True or false:** The word 'bit' is short for 'binary digit.'

<details>
<summary>Answer</summary>

**True**: A bit, short for binary digit, is the smallest unit of data in computing, representing a single 1 or 0.

</details>

**4. True or false:** 4 bits can represent 32 different values.

<details>
<summary>Answer</summary>

**False**: 4 bits can represent 2 x 2 x 2 x 2 = 16 different values. You would need 5 bits to reach 32 values.

</details>
