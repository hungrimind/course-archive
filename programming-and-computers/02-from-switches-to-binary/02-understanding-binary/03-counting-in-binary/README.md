# Counting in Binary

In our everyday system, each place is worth 10 times more than the one to its right: 1, 10, 100, 1000. In binary, each place is worth **2 times** more: 1, 2, 4, 8.

To read a binary number, add up the places where there's a 1:

```text
1011  =  8 + 0 + 2 + 1  =  11
```

The rightmost digit is worth 1, next is 2, then 4, then 8. Wherever you see a 1, add that place's value. Wherever you see a 0, skip it.
