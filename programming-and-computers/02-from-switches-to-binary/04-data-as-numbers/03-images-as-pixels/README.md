# Images as Pixels

A digital image is a grid of tiny dots called **pixels**. Each pixel stores its own color as red, green, and blue values.

A 1920x1080 screen has over 2 million pixels. Each one holds three numbers (one per color channel), so a single frame of what you see on screen is really just millions of numbers arranged in a grid. Zoom in far enough on any photo and you'll see the individual colored squares.

## True or False

**1. True or false:** Each pixel in a digital image stores its color as red, green, and blue values.

<details>
<summary>Answer</summary>

**True**: A pixel holds three numbers: one for red, one for green, and one for blue. By mixing different amounts of these three colors, the pixel can represent virtually any color.

</details>

**2. True or false:** A 1920x1080 screen has about 2 million pixels.

<details>
<summary>Answer</summary>

**True**: 1920 multiplied by 1080 equals 2,073,600, which is just over 2 million pixels. Each one holds its own color information.

</details>

**3. True or false:** A single pixel stores just one number to represent its color.

<details>
<summary>Answer</summary>

**False**: A pixel stores three numbers, one for each color channel: red, green, and blue. It takes all three values together to define the exact color of that dot on screen.

</details>

**4. True or false:** If you zoom in far enough on a photo, the image stays smooth and continuous.

<details>
<summary>Answer</summary>

**False**: If you zoom in far enough on any digital image, you will see individual colored squares: the pixels. A digital image is a grid of dots, not a smooth continuous surface.

</details>
