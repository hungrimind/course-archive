# Text as Numbers

Computers store every letter as a number. A standard called **ASCII** assigns a number to each character: 'A' is 65, 'B' is 66, a space is 32.

ASCII only covers English letters and basic symbols. **Unicode** extends the idea to every writing system on earth, plus emoji. The grinning face emoji is number 128,512. Behind the scenes, every piece of text you read on a screen is just a sequence of numbers that your device knows how to draw.
