# Colors as Numbers

Every color on your screen is made of three numbers: a **red** value, a **green** value, and a **blue** value. Each one ranges from 0 to 255, fitting perfectly in one byte.

Pure red is (255, 0, 0). Pure white is (255, 255, 255). Black is (0, 0, 0). By mixing these three channels at different strengths, your screen can produce over 16 million colors, all from just three numbers per dot.

## Quiz

**1. Which three color channels combine to make every color on your screen?**

- A) Red, Yellow, Blue
- B) Red, Green, Blue
- C) Cyan, Magenta, Yellow
- D) Black, White, Gray

<details>
<summary>Answer</summary>

- B) Red, Green, Blue

Screens use the RGB model: red, green, and blue light mixed at different strengths. Combining these three channels can produce over 16 million distinct colors.

</details>

**2. What range of values does each color channel use?**

- A) 0 to 99
- B) 0 to 127
- C) 0 to 255
- D) 0 to 1000

<details>
<summary>Answer</summary>

- C) 0 to 255

Each channel ranges from 0 to 255, which fits exactly in one byte (8 bits). That gives 256 possible intensity levels per channel.

</details>

**3. Which RGB values represent pure white?**

- A) (0, 0, 0)
- B) (255, 0, 0)
- C) (128, 128, 128)
- D) (255, 255, 255)

<details>
<summary>Answer</summary>

- D) (255, 255, 255)

White is all three channels at maximum intensity: (255, 255, 255). Black is the opposite, (0, 0, 0), where all channels are off.

</details>
