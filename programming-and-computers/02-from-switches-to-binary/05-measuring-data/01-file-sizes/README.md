# File Sizes

Data size is measured in bytes. Since files get big fast, we use larger units:

- **Kilobyte (KB)**: about 1,000 bytes. A short text message.
- **Megabyte (MB)**: about 1 million bytes. A high-quality photo.
- **Gigabyte (GB)**: about 1 billion bytes. A movie.
- **Terabyte (TB)**: about 1 trillion bytes. Hundreds of movies.

Each step up is roughly 1,000 times the previous one. When your phone says "64 GB storage," it means it can hold about 64 billion bytes of data.
