# Programming Environments Today

Modern **code editors** are a long way from terminals and punch cards. They highlight your code in color, catch mistakes as you type, suggest what you might write next, and let you run your program with a single click.

The core idea hasn't changed: you're still giving instructions to a computer. The tools have just gotten *dramatically* better at helping you do it.
