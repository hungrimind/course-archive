# What is Source Code?

**Source code** is the plain text that programmers write. It looks like structured English mixed with symbols and punctuation, readable by humans, runnable by machines.

These text files are the raw instructions that eventually become a working program. Everything you see a computer do started as someone's source code.

## Quiz

**1. What is source code?**

- A) The physical wires inside a computer
- B) The plain text that programmers write as instructions
- C) A picture of what a program will look like
- D) The electricity that powers a machine

<details>
<summary>Answer</summary>

- B) The plain text that programmers write as instructions

Source code is the plain text programmers write. It is readable by humans and becomes the raw instructions a machine runs.

</details>

**2. Which best describes what source code looks like?**

- A) Only numbers in long rows
- B) Structured English mixed with symbols and punctuation
- C) Hand-drawn diagrams and charts
- D) Audio recordings of commands

<details>
<summary>Answer</summary>

- B) Structured English mixed with symbols and punctuation

Source code reads like structured English combined with symbols and punctuation, making it human-readable while still being runnable by machines.

</details>

**3. What's the relationship between source code and working programs?**

- A) Programs and source code are unrelated
- B) Source code replaces the need for programs
- C) Everything a computer does started as someone's source code
- D) Working programs are written without source code

<details>
<summary>Answer</summary>

- C) Everything a computer does started as someone's source code

Every working program begins as source code. Those text files are the raw instructions that eventually become the software you use.

</details>
