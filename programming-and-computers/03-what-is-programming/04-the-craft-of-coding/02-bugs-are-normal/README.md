# Bugs Are Normal

A **bug** is when your program does something you didn't intend. Every programmer creates them; it's completely normal.

**Debugging** is the detective work of tracking down what went wrong and fixing it. Even the best programmers spend more time debugging than writing new code.

## True or False

**1. True or false:** Good programmers never create bugs in their code.

<details>
<summary>Answer</summary>

**False**: Every programmer creates bugs, and it is completely normal. Even the best programmers in the world introduce bugs regularly. What matters is the ability to find and fix them.

</details>

**2. True or false:** Debugging means tracking down what went wrong in your code and fixing it.

<details>
<summary>Answer</summary>

**True**: Debugging is the detective work of finding the source of a problem and correcting it. It is a core part of programming, not a sign that something went wrong.

</details>

**3. True or false:** Experienced programmers spend more time debugging than writing new code.

<details>
<summary>Answer</summary>

**True**: Even the best programmers spend a large portion of their time debugging. Writing new code is only part of the job. Understanding and fixing unexpected behavior is where much of the real work happens.

</details>

**4. True or false:** A bug means the programming language itself is broken.

<details>
<summary>Answer</summary>

**False**: A bug is when your program does something you did not intend. It is a mistake in your instructions, not a flaw in the language. The language did exactly what you told it to do; the problem is that you told it the wrong thing.

</details>
