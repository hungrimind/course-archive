# Edit, Run, Debug

Programmers work in a tight loop: **write** some code, **run** it to see what happens, **find** problems, and **fix** them. Then repeat.

This cycle happens hundreds of times a day. Progress doesn't come from one perfect attempt; it comes from many small iterations. *Every working program was shaped by this loop.*
