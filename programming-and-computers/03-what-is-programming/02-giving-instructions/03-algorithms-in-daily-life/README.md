# Algorithms in Daily Life

An **algorithm** is just a step-by-step procedure for solving a problem. You already use them every day: a recipe, directions to a friend's house, the steps to tie your shoes.

Programming is writing algorithms in a language a computer can follow. The thinking is the same; only the audience changes.
