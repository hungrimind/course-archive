# What is Programming?

**Programming** is writing a precise set of instructions for a computer to follow. The computer does exactly what you say, nothing more, nothing less.

Your job as a programmer is to describe every step clearly enough that a machine with zero intuition can carry it out perfectly.

- B) Writing a precise set of instructions for a computer to follow
- C) Designing the physical parts of a computer
- D) Teaching a computer to think on its own

<summary>Answer</summary>

- B) Writing a precise set of instructions for a computer to follow

Programming is writing a precise set of instructions for a computer to follow. The computer does exactly what you say, nothing more, nothing less.

**2. Why must a programmer describe every step clearly?**

- A) Because computers get bored with long instructions
- B) Because computers choose the fastest path on their own
- C) Because a machine has zero intuition and only does what it's told
- D) Because computers rewrite instructions to fit their needs

<details>
<summary>Answer</summary>
