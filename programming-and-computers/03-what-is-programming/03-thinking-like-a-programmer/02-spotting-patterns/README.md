# Spotting Patterns

**Pattern recognition** is noticing when you're doing the same thing over and over. If you send a welcome email to every new user, that's a pattern.

Once you spot a pattern, you can write one set of instructions that handles all the cases. *Instead of solving the same small problem a hundred times, you solve it once.*
