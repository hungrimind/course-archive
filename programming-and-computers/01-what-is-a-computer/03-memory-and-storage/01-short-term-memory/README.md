# Short-Term Memory

**RAM** (Random Access Memory) is your computer's short-term memory. It holds whatever the computer is actively working on right now: the apps you have open, the web page you're viewing, the song that's playing.

RAM is fast. The CPU can grab data from RAM almost instantly, which is why your open apps feel responsive. The tradeoff is that RAM is **volatile**: when you turn off the computer, everything in RAM disappears. That's why unsaved work is lost during a power outage.

## True or False

**1. True or false:** If your laptop loses power while you are typing a document you never saved, that document is gone because it only existed in RAM.

<details>
<summary>Answer</summary>

**True**: RAM is volatile, it only holds data while the power is on. Anything in RAM that hasn't been saved to permanent storage is lost when the power goes out. This is why saving your work matters.

</details>

**2. True or false:** RAM keeps all your data safe even after you shut down your computer.

<details>
<summary>Answer</summary>

**False**: RAM is short-term memory that gets wiped when the power turns off. It is fast but temporary. Long-term storage (like a hard drive or SSD) is what keeps data after shutdown.

</details>

**3. True or false:** RAM holds the apps and data your computer is actively working on right now.

<details>
<summary>Answer</summary>

**True**: When you open an app or a file, it gets loaded into RAM so the CPU can access it quickly. RAM acts as a workspace for everything your computer is currently doing.

</details>

**4. True or false:** RAM is slower than long-term storage but can hold more data.

<details>
<summary>Answer</summary>

**False**: It's actually the opposite. RAM is much faster than long-term storage, which is why active work gets loaded there. However, RAM is more expensive and typically has less capacity than a hard drive or SSD.

</details>
