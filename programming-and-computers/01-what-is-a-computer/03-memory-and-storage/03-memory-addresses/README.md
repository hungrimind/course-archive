# Memory Addresses

Every spot in RAM has a unique number called a **memory address**. Think of RAM as a long row of numbered mailboxes: mailbox 0, mailbox 1, mailbox 2, and so on, up into the billions.

When the CPU needs a piece of data, it doesn't search around for it. It asks for the exact address: *"give me what's in mailbox 4072."* When it's done processing, it writes the result back to a specific address. This numbering system is what makes RAM so fast, every location is directly accessible by its address.

## Quiz

**1. What is a memory address?**

- A) The physical location of your computer on a network
- B) A unique number that identifies a specific spot in RAM
- C) The name of a file stored on your hard drive
- D) A password used to unlock protected memory

<details>
<summary>Answer</summary>

- B) A unique number that identifies a specific spot in RAM

A memory address is a unique number that labels each spot in RAM, similar to the way each mailbox in a row has its own number. This lets the CPU refer to any specific location in memory.

</details>

**2. When the CPU needs a piece of data from RAM, how does it find it?**

- A) It scans every location in RAM one by one until it finds the data
- B) It asks for the data by its exact memory address
- C) It guesses the location based on what the user is doing
- D) It waits for RAM to send all the data automatically

<details>
<summary>Answer</summary>

- B) It asks for the data by its exact memory address

The CPU doesn't search through RAM. It asks for the exact address, like saying 'give me what's in mailbox 4072.' This direct lookup is what makes RAM so fast.

</details>

**3. Why is the numbered-address system one of the reasons RAM is so fast?**

- A) Because numbers are easier for humans to read than letters
- B) Because it lets RAM compress data to take up less space
- C) Because every location can be accessed directly by its address, with no searching needed
- D) Because it prevents the CPU from making mistakes with data

<details>
<summary>Answer</summary>

- C) Because every location can be accessed directly by its address, with no searching needed

Because each RAM location has a unique address, the CPU can jump straight to any spot without searching. This direct access is a key reason RAM is extremely fast.

</details>
