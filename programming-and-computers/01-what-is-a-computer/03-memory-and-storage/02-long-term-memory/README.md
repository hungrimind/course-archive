# Long-Term Memory

**Storage**, a hard drive or SSD, is your computer's long-term memory. Unlike RAM, it keeps your files, photos, and apps even when the power is off.

The tradeoff is speed. Storage is much slower than RAM. That's why opening an app for the first time takes a moment, the computer is copying it from slow storage into fast RAM so the CPU can work with it. You get permanence in exchange for patience.

## True or False

**1. True or false:** Storage keeps your files even when the computer is turned off.

<details>
<summary>Answer</summary>

**True**: That is the key advantage of storage (hard drives and SSDs). Unlike RAM, which is wiped when power is lost, storage retains your photos, apps, and documents permanently.

</details>

**2. True or false:** Storage is faster than RAM, which is why we use it for long-term files.

<details>
<summary>Answer</summary>

**False**: Storage is actually much slower than RAM. We use it for long-term files because it keeps data without power, not because of speed. The tradeoff is permanence in exchange for slower access.

</details>

**3. True or false:** When you open an app, the computer copies it from storage into RAM so the CPU can work with it.

<details>
<summary>Answer</summary>

**True**: Apps live on storage permanently, but the CPU needs data in fast RAM to process it. That is why opening an app for the first time takes a moment: the computer is loading it from slow storage into fast RAM.

</details>

**4. True or false:** RAM and storage do the same job, they are just different brands of memory.

<details>
<summary>Answer</summary>

**False**: RAM and storage serve different purposes. RAM is fast, temporary workspace that loses data when power is off. Storage is slower, permanent memory that keeps files indefinitely. They work together but are not interchangeable.

</details>
