# Input, Process, Output

Every computer follows a three-step pattern: **input**, **process**, **output**.

**Input** is anything you feed the computer: a screen tap, a keyboard press, a voice command. **Process** is the computer figuring out what to do with that input. **Output** is the result: a sound, an image on screen, a message sent.

Tap a letter on your phone keyboard: your finger's touch is input, the phone figures out which letter you meant (process), and the letter appears on screen (output). This cycle happens so fast it feels instant, but it's the same three steps every single time.
