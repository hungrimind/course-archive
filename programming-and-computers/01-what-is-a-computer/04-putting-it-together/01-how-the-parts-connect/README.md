# How the Parts Connect

The CPU, RAM, and storage work together in a constant conversation. When you open an app, the computer copies it from **storage** into **RAM**. The **CPU** then reads instructions and data from RAM, does the work, and writes results back to RAM. When you hit "save," the data flows from RAM back to storage for safekeeping.

These parts are connected by pathways called **buses**: think of them as highways that data travels along. The faster and wider the bus, the more data can flow between parts at once.
