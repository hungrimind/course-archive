# Fetch, Decode, Execute

The CPU runs a never-ending three-step loop called the **fetch-decode-execute cycle**.

**Fetch**, grab the next instruction from RAM using its memory address. **Decode**, figure out what that instruction is asking (add? compare? move data?). **Execute**, actually do it.

Then the cycle repeats with the next instruction. Billions of times per second, the CPU is fetching, decoding, and executing. This simple loop is the heartbeat of every computer, from the phone in your pocket to a warehouse-sized supercomputer.
