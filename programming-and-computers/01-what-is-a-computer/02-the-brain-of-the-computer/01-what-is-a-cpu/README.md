# What is a CPU?

The **CPU** (Central Processing Unit) is the brain of your computer. It's the part that actually does the "process" step from input-process-output.

A CPU only knows a handful of very simple operations: add two numbers, compare two values, move a piece of data from one place to another. That's about it. The magic is that it does these tiny steps *extremely* fast, millions of them just to open an app. Every complex thing your computer does is really just a long chain of these dead-simple instructions.

## Quiz

**1. What does CPU stand for, and what is its role in a computer?**

- A) Computer Power Unit: it supplies electricity to the computer
- B) Central Processing Unit: it is the brain that handles the 'process' step
- C) Core Peripheral Unit: it connects devices like keyboards and mice
- D) Central Program Utility: it stores all the programs on the computer

<details>
<summary>Answer</summary>

- B) Central Processing Unit: it is the brain that handles the 'process' step

CPU stands for Central Processing Unit, and it is the part of the computer that actually performs the 'process' step in input-process-output. It is often called the brain of the computer because it carries out instructions.

</details>

**2. Which of the following best describes the kinds of operations a CPU can perform directly?**

- A) Complex tasks like editing a photo or playing a video in a single step
- B) Only operations related to displaying things on the screen
- C) A handful of very simple operations like adding numbers, comparing values, and moving data
- D) Any task a human can describe, using plain English instructions

<details>
<summary>Answer</summary>

- C) A handful of very simple operations like adding numbers, comparing values, and moving data

A CPU only understands a handful of very simple operations such as adding numbers, comparing values, and moving data between places. Complex tasks are built by chaining millions of these tiny steps together.

</details>

**3. How does a CPU manage to do complex things like opening an app if it only knows simple operations?**

- A) It secretly uses a second, more powerful chip for complex work
- B) It runs millions of those simple operations extremely fast, one after another
- C) It asks the user to break the task down into smaller steps first
- D) It learns new operations automatically as you use the computer

<details>
<summary>Answer</summary>

- B) It runs millions of those simple operations extremely fast, one after another

The CPU's power comes from speed: it performs millions of simple instructions per second. Every complex action is really just a long chain of those dead-simple steps executed incredibly quickly.

</details>
