# Clock Speed

A CPU has an internal clock that ticks at a steady rhythm. Each tick is one chance for the CPU to perform a tiny step. The faster the clock ticks, the more work gets done per second.

**Clock speed** is measured in **gigahertz (GHz)**. One GHz means one billion ticks per second. So when you see "3 GHz" on a spec sheet, that CPU gets 3 billion chances to do something every single second.

> [!info]
> Clock speed isn't the only thing that determines how fast a computer feels. But it's one of the most fundamental pieces of the puzzle.

## True or False

**1. True or false:** A 3 GHz CPU performs 3 million operations per second.

<details>
<summary>Answer</summary>

**False**: GHz means billions, not millions. A 3 GHz CPU gets 3 billion ticks per second.

</details>

**2. True or false:** GHz stands for gigahertz, the unit used to measure a CPU's clock speed.

<details>
<summary>Answer</summary>

**True**: Gigahertz (GHz) is the standard unit for measuring how many clock ticks a CPU completes per second.

</details>

**3. True or false:** A faster clock speed always means a faster computer overall.

<details>
<summary>Answer</summary>

**False**: Clock speed is just one factor. Other things like the number of cores, memory speed, and how efficiently the CPU handles instructions also matter.

</details>
