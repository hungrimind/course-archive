# Compiled Languages

A **compiled language** translates your entire program into machine code *before* it runs. This translation step is called **compiling**.

You write code, the compiler converts all of it into a machine code file, and then that file runs directly on the CPU. The translation only happens once, after that, the program runs fast every time.

Languages like C, Go, and Rust work this way. *Think of it like translating an entire book before handing it to a reader.*

## True or False

**1. True or false:** A compiled language translates the entire program into machine code before the program runs.

<details>
<summary>Answer</summary>

**True**: That is exactly what compilation means, the entire source code is translated into machine code ahead of time, and then the resulting program can be executed directly by the CPU.

</details>

**2. True or false:** Compiled programs need to be re-translated every time you run them.

<details>
<summary>Answer</summary>

**False**: Compiling happens once. After the program is compiled into machine code, you can run the resulting file as many times as you want without re-compiling.

</details>

**3. True or false:** C, Go, and Rust are examples of compiled languages.

<details>
<summary>Answer</summary>

**True**: C, Go, and Rust are all compiled languages. Their source code is translated entirely into machine code by a compiler before execution.

</details>

**4. True or false:** Compiling a program is like having a live translator read one sentence at a time.

<details>
<summary>Answer</summary>

**False**: That describes interpretation, not compilation. Compiling is like translating an entire book before anyone reads it, the whole translation is done up front.

</details>
