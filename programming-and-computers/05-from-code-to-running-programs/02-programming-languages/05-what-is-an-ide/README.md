# What is an IDE?

An **IDE** (Integrated Development Environment) is where programmers write code. *Think of it like a word processor, but for code.*

It highlights errors as you type, suggests what to write next, and has built-in tools to run and test your program, all in one place. Without an IDE, you'd be writing code in a plain text file with no help at all.

> [!tip] Popular IDEs include VS Code, IntelliJ, and Xcode.
