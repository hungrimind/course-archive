# What is a Language?

A **programming language** lets you write instructions in something close to English, and a special program automatically translates them into the machine code the CPU needs.

Instead of `MOV AL, 61h`, you write something like `x = 97`. The language handles the translation for you.

This is the key idea: you describe *what* you want to happen, and the language figures out *how* to tell the CPU. It's a bridge between human thinking and binary instructions.

## Quiz

**1. What is the main purpose of a programming language?**

- A) To let you write instructions in a human-friendly way that get translated into machine code
- B) To replace the CPU with software
- C) To store files on a hard drive
- D) To let CPUs read English sentences directly

<details>
<summary>Answer</summary>

- A) To let you write instructions in a human-friendly way that get translated into machine code

A programming language bridges human thinking and CPU instructions by letting you write readable code that a translator converts into machine code.

</details>

**2. When you write x = 97 in a programming language, what happens behind the scenes?**

- A) The CPU directly understands the English text
- B) The language translates it into the machine code the CPU needs
- C) Nothing, the CPU ignores it
- D) It is stored as plain text and never executed

<details>
<summary>Answer</summary>

- B) The language translates it into the machine code the CPU needs

You describe what you want, and the language automatically translates it into the binary instructions the CPU actually runs.

</details>
