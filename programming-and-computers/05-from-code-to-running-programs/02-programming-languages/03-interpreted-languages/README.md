# Interpreted Languages

An **interpreted language** translates your code line by line *as it runs*. There's no separate compile step, you write code and immediately execute it.

*If compiled is translating an entire book upfront, interpreted is like having a live translator reading one sentence at a time.*

This makes development faster and more flexible, but the program usually runs slower since translation happens every time. Python and JavaScript are popular interpreted languages.

## True or False

**1. True or false:** An interpreted language translates code line by line as the program runs.

<details>
<summary>Answer</summary>

**True**: Interpreted languages are translated on the fly, each line is read, translated, and executed one at a time, like a live translator working through a speech sentence by sentence.

</details>

**2. True or false:** Interpreted languages generally run faster than compiled languages.

<details>
<summary>Answer</summary>

**False**: Interpreted languages are generally slower at execution because the translation happens during runtime. Compiled languages translate everything up front, so the resulting program runs faster.

</details>

**3. True or false:** Python and JavaScript are examples of interpreted languages.

<details>
<summary>Answer</summary>

**True**: Python and JavaScript are commonly used interpreted languages. They do not require a separate compile step before running.

</details>

**4. True or false:** Interpreted languages require a separate compile step before you can run your code.

<details>
<summary>Answer</summary>

**False**: One key advantage of interpreted languages is that there is no compile step. You can write code and run it immediately, which speeds up development.

</details>
