# Your First Language

The best first language is the one that matches what you want to build. Want websites? **JavaScript**. Curious about AI or data? **Python**. Interested in mobile apps? **Swift**, **Kotlin**, or **Dart**.

The core concepts, variables, logic, loops, functions, are the same across every language. Once you learn one, picking up a second is dramatically easier. So don't overthink it. Just pick one and start building.
