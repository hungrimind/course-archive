# Data Science

**Python** dominates data science and artificial intelligence. Its simple syntax makes it approachable, and its massive collection of pre-built tools means you rarely start from scratch.

Need to analyze a spreadsheet with a million rows? A few lines of Python. Want to train a machine learning model to recognize images? Python has libraries for that too. It's the go-to language for anyone working with data.

## Quiz

**1. Which language dominates data science and artificial intelligence?**

- A) Assembly
- B) Python
- C) HTML
- D) C++

<details>
<summary>Answer</summary>

- B) Python

Python is the go-to language for data science and AI thanks to its simple syntax and enormous ecosystem of ready-made libraries.

</details>

**2. Why is Python so popular for working with data?**

- A) It is the only language the CPU can understand
- B) It has simple syntax and a huge collection of pre-built tools
- C) It runs faster than every other language
- D) It was designed exclusively for spreadsheets

<details>
<summary>Answer</summary>

- B) It has simple syntax and a huge collection of pre-built tools

Python's approachable syntax lowers the barrier to entry, and its massive library ecosystem means you rarely have to build things from scratch.

</details>
