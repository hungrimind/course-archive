# Mobile Apps

Phone apps use specialized languages: **Swift** for iPhones and **Kotlin** for Android. Each platform has its own language because the underlying systems are different.

Some tools let you write code once and run it on both platforms. **Flutter** (using the Dart language) and **React Native** (using JavaScript) are popular choices. You trade a bit of platform-specific control for the convenience of not building everything twice.
