# Web Development

Nearly every website you visit is built with three languages working together: **HTML** gives the page its structure, **CSS** makes it look good, and **JavaScript** makes it interactive.

JavaScript has become one of the most widely used languages in the world. It started in web browsers but now runs servers, mobile apps, and more. If you've ever clicked a button on a website and something happened without the page reloading, that was JavaScript.
