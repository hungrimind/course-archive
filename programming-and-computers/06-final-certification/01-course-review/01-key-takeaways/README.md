# Key Takeaways

A computer is a machine that takes input, processes it, and produces output. Inside, billions of tiny transistor switches flip between ON and OFF, giving us binary, the 1s and 0s behind all digital data.

Everything is numbers: text, colors, images, and sound are all encoded as patterns of bits. A byte (8 bits) can represent 256 values, and from there we scale up to kilobytes, megabytes, and beyond.

Programming is writing precise, step-by-step instructions for a computer. The core concepts, **variables**, **conditions**, **loops**, **collections**, and **functions**, appear in every programming language. They're ideas, not syntax.

The journey from source code to a running program follows the same path it always has: human-readable instructions get translated into machine code the CPU can execute. We've just made the human side easier over time, from punch cards to modern IDEs.

Pick a language, start building, and remember: every expert was once a beginner.

## Quiz

**1. What is the main job of the CPU inside a computer?**

- A) To permanently store files and documents
- B) To fetch, decode, and execute instructions
- C) To display images on the screen
- D) To connect the computer to the internet

<details>
<summary>Answer</summary>

- B) To fetch, decode, and execute instructions

The CPU is the brain of the computer, and its core loop is fetch-decode-execute: it grabs an instruction, figures out what it means, and carries it out. This cycle happens billions of times per second.

</details>

**2. Why can a single byte represent 256 different values?**

- A) Because a byte is made of 256 transistors
- B) Because 256 is the maximum number in hexadecimal
- C) Because a byte is 8 bits, and 2 to the power of 8 equals 256
- D) Because computers count in groups of 256

<details>
<summary>Answer</summary>

- C) Because a byte is 8 bits, and 2 to the power of 8 equals 256

A byte contains 8 bits, and each bit can be 0 or 1, giving 2^8 = 256 possible combinations. This is why text, colors, and other data are often built from byte-sized chunks.

</details>

**3. What does it mean to say computers are 'literal'?**

- A) They can only understand the English language
- B) They do exactly what you tell them, nothing more, nothing less
- C) They can guess what you meant if your instructions are unclear
- D) They only work with literal numbers, not text

<details>
<summary>Answer</summary>

- B) They do exactly what you tell them, nothing more, nothing less

Computers follow instructions precisely without inferring intent, which is why programming requires clear, step-by-step thinking. A small mistake in your instructions leads to a bug.

</details>

**4. Which of the following best describes a function in programming?**

- A) A single value that never changes
- B) A type of loop that runs forever
- C) A reusable block of instructions that can take inputs and return an output
- D) A list of key-value pairs

<details>
<summary>Answer</summary>

- C) A reusable block of instructions that can take inputs and return an output

Functions let you package logic once and reuse it anywhere, often taking inputs and producing an output. They are one of the core building blocks of every programming language.

</details>

**5. What is the key difference between compiled and interpreted languages?**

- A) Compiled languages are translated to machine code ahead of time, while interpreted languages are translated and run line-by-line
- B) Compiled languages only run on phones, interpreted languages only run on desktops
- C) Interpreted languages do not use variables or loops
- D) Compiled languages do not need a CPU to run

<details>
<summary>Answer</summary>

- A) Compiled languages are translated to machine code ahead of time, while interpreted languages are translated and run line-by-line

Compiled languages convert all the source code into machine code before running, while interpreted languages translate and execute it on the fly. Either way, the CPU ultimately runs machine code.

</details>
