# Why Functions Matter

Functions break a big program into small, named pieces. Each piece does one job, has a clear name, and can be reused anywhere.

If something breaks, you fix it in one place and every spot that calls that function gets the fix for free. This is the core idea behind **"don't repeat yourself"**, one of the most important principles in programming.

## Quiz

**1. What do functions do for a big program?**

- A) They make the program use less memory automatically
- B) They break it into small, named pieces that each do one job
- C) They make the program colorful and nice to look at
- D) They translate the program into another language

<details>
<summary>Answer</summary>

- B) They break it into small, named pieces that each do one job

Functions split a big program into small, reusable pieces with clear names. Each one does a single job and can be called from anywhere.

</details>

**2. What does the principle "don't repeat yourself" mean in programming?**

- A) Never use the same variable name twice
- B) Avoid writing the same logic in many places by putting it in one reusable function
- C) Only run the program once to save time
- D) Say every instruction out loud just once

<details>
<summary>Answer</summary>

- B) Avoid writing the same logic in many places by putting it in one reusable function

"Don't repeat yourself" means you should write a piece of logic once, usually as a function, and reuse it. This keeps your code shorter and easier to maintain.

</details>

**3. Why is fixing a bug easier when the logic lives inside a function?**

- A) Functions warn you with a sound when something is wrong
- B) You fix it in one place and every call to that function gets the fix
- C) Bugs cannot happen inside a function at all
- D) Functions automatically rewrite themselves

<details>
<summary>Answer</summary>

- B) You fix it in one place and every call to that function gets the fix

When logic lives in one function, a single fix updates every spot that uses it. Without functions, you would have to find and fix the same bug in many places.

</details>
