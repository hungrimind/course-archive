# Inputs to a Function

Functions can accept inputs called **parameters**. A *makeGreeting* function might take a name as input and produce "Hello, Alice!" or "Hello, Bob!" depending on what you pass in.

The recipe stays the same, the ingredients change. That's what makes functions flexible: one set of instructions that works for many different inputs.
