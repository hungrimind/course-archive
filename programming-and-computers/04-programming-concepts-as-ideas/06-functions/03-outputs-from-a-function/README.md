# Outputs from a Function

A function can send back a result called a **return value**. An *add* function takes two numbers, adds them, and hands you back the sum.

The calling code receives this result and can use it however it wants, store it in a variable, pass it to another function, or display it on screen. The function does its job and delivers an answer.

## Fill in the Blanks

Fill in the blanks:

```typescript
function add(a, b) {
  __(1)__ a + b;
}

let result = __(2)__(2, 3);
// result is 5
```

<details>
<summary>Answer</summary>

1. `return`
2. `add`

</details>
