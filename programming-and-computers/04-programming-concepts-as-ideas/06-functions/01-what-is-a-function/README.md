# What is a Function?

A **function** is a named set of instructions you can reuse. Think of it as a recipe card: you write the steps once, give the recipe a name, and then just say *"do the calculateTotal recipe"* whenever you need it.

Without functions, you'd copy and paste the same instructions every time. With them, you write the logic once and call it by name from anywhere.

## Fill in the Blanks

Fill in the blanks:

```
A banking app calculates fees in many places. Instead of copying the same steps each time, the developer writes a __(1)__ once and then __(2)__ it by __(3)__ wherever the fee is needed.
```

<details>
<summary>Answer</summary>

1. `function`
2. `calls`
3. `name`

</details>
