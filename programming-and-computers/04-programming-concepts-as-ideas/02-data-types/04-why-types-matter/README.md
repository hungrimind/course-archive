# Why Types Matter

You can add 5 + 3 and get 8. You can't add 5 + "banana". That makes no sense.

**Types** tell the computer what kind of value it's dealing with so it knows what operations are allowed. Numbers can be added, strings can be joined together, booleans can be checked. Mixing them up without converting first is like trying to pour soup into an electrical outlet, wrong container, wrong operation.

## Quiz

**1. What is the main job of a type in programming?**

- A) To make the code run faster
- B) To tell the computer what kind of value it is and what operations are allowed
- C) To give every value a unique name
- D) To hide values from other parts of the program

<details>
<summary>Answer</summary>

- B) To tell the computer what kind of value it is and what operations are allowed

Types describe what kind of value something is so the computer knows which operations make sense. Numbers can be added, strings can be joined, and booleans can be checked.

</details>

**2. Why does 5 + "banana" usually cause a problem?**

- A) Because the word banana is too long
- B) Because you cannot have letters in a program
- C) Because you are mixing a number and a string without converting first
- D) Because 5 is too small of a number

<details>
<summary>Answer</summary>

- C) Because you are mixing a number and a string without converting first

A number and a string are different types, and adding them together mixes operations that do not fit. You have to convert one to match the other before combining them.

</details>

**3. Which pairing of type and operation makes sense?**

- A) Joining two booleans into one long word
- B) Adding two numbers together to get a total
- C) Subtracting one string from another
- D) Multiplying a true/false value by a word

<details>
<summary>Answer</summary>

- B) Adding two numbers together to get a total

Adding numbers is a natural operation because both values share the same numeric type. The other options mix types in ways that do not have a sensible meaning.

</details>
