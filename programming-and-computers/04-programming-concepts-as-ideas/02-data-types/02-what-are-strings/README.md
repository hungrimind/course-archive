# What Are Strings?

A **string** is text, a sequence of characters strung together like beads on a necklace. Letters, digits, spaces, punctuation, emoji: all fair game.

The critical thing: the string "42" is *text*, not a number. The computer sees it the same way it sees "hello", just characters. You can't do math with it unless you explicitly convert it to a number first.

## True or False

**1. True or false:** The text "100" is a number, not a string, because it contains digits.

<details>
<summary>Answer</summary>

**False**: When digits are wrapped in quotes they are treated as text (a string), not a number. You cannot do math with them until they are converted.

</details>

**2. True or false:** A string can contain letters, digits, spaces, and symbols all together.

<details>
<summary>Answer</summary>

**True**: A string is any sequence of characters, so it can mix letters, digits, spaces, and symbols freely.

</details>

**3. True or false:** You can do math with a string like "42" without converting it first.

<details>
<summary>Answer</summary>

**False**: A string that looks like a number is still text. It must be converted to a number before math operations work.

</details>
