# Number Types

Computers split numbers into two camps: **whole numbers** (like 42) and **decimal numbers** (like 3.14).

Whole numbers are exact, great for counting things like lives, items, or steps. Decimals handle fractions and precision, but they carry a quirk: computers sometimes produce tiny rounding errors, like getting 0.30000000000000004 instead of 0.3. It's a trade-off baked into how machines store decimals.
