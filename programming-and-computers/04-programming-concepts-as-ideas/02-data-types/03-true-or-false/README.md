# True or False

A **boolean** is the simplest data type: it's either *true* or *false*. That's it, two possible values.

Is the user logged in? Is the score above 100? Has the file finished downloading? Every yes-or-no question in a program boils down to a boolean. They're the foundation of every decision a program makes.

## Fill in the Blanks

Fill in the blanks:

```typescript
let isLoggedIn = __(1)__;
let isGameOver = __(2)__;

if (isLoggedIn) {
  console.log("Welcome back!");
}
```

<details>
<summary>Answer</summary>

1. `true`
2. `false`

</details>
