# What Are Lists?

A **list** is an ordered collection of items, a shopping list, a playlist, a roster of names. Each item has a position: first, second, third, and so on.

Without lists, you'd need a separate variable for every single item. Ten songs would mean ten variables. A thousand users would mean a thousand variables. Lists let you group related items under one name and work with them as a set.
