# Multiple Conditions

Sometimes a fork in the road has more than two paths. A grading system doesn't just say pass or fail, it says A, B, C, D, or F.

Programs handle this by chaining conditions: *if the grade is above 90, show A; if above 80, show B; if above 70, show C; otherwise, show F.* The computer checks each condition in order and takes the first one that's true.

## Matching

Sort each item into the right category: **Simple If/Else (Two Paths)**, **Chained Conditions (Many Paths)**

- Did the payment succeed or fail?
- Grade the score as A, B, C, D, or F
- Is the light on or off?
- Is the user logged in or not?
- Set the ticket price by age group
- Show different shipping options by region
