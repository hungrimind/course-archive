# If This, Then That

An **if statement** lets a program make a decision. *If the password is correct, let the user in.* The program checks a condition, a boolean question, and only runs certain instructions when the answer is true.

Without this, programs would do the exact same thing every time, no matter what. Decisions are what make software feel responsive.

## Fill in the Blanks

Fill in the blanks:

```typescript
let temperature = 105;

__(1)__ (temperature > __(2)__) {
  let status = "__(3)__";
  console.log(status);
}
```

<details>
<summary>Answer</summary>

1. `if`
2. `100`
3. `boiling`

</details>
