# Values That Stay

A **constant** is a variable you set once and never change. Think of it as a box sealed shut with tape after you fill it.

The speed of gravity in a game, the maximum password length, the value of pi: these shouldn't change while the program runs. Marking them as constants tells the computer (and anyone reading your code) that this value is meant to stay put.

## Quiz

**1. What is a constant?**

- A) A variable whose value changes often as the program runs
- B) A variable you set once and never change
- C) A type of number that can only be whole
- D) A placeholder that stores nothing

<details>
<summary>Answer</summary>

- B) A variable you set once and never change

A constant is a variable you set once and never change, like a box sealed shut after being filled. This keeps values that shouldn't shift, such as pi, safely locked in place.

</details>

**2. Which of these is the best candidate to store as a constant?**

- A) A player's current score in a game
- B) The text the user just typed into a chat box
- C) The value of pi used in math calculations
- D) The current time of day

<details>
<summary>Answer</summary>

- C) The value of pi used in math calculations

Pi never changes, so it is a perfect constant. Scores, user input, and the current time all change while the program runs, so they should be regular variables.

</details>

**3. Why mark a value as a constant instead of a regular variable?**

- A) It makes the program run on more devices
- B) It signals the value is meant to stay put and protects it from being changed
- C) It automatically makes the value a number
- D) It hides the value from other parts of the program

<details>
<summary>Answer</summary>

- B) It signals the value is meant to stay put and protects it from being changed

Marking a value as constant tells the computer and other readers that this value should not change, which prevents accidental edits and makes the code easier to understand.

</details>
