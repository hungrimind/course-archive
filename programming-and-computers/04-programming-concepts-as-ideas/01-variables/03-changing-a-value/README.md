# Changing a Value

Variables can change. If *score* starts at 0 and the player earns a point, you replace the 0 with a 1. The old value is gone, overwritten by the new one.

This is called **reassignment**. The box keeps its label, but you swap out what's inside. A program that can't update its variables would be like a scoreboard stuck on zero.

## True or False

**1. True or false:** When you reassign a variable, the old value is kept alongside the new one.

<details>
<summary>Answer</summary>

**False**: The old value is replaced and gone. The variable only holds one value at a time.

</details>

**2. True or false:** Reassigning a variable changes the value inside, but the label stays the same.

<details>
<summary>Answer</summary>

**True**: Exactly right. The name of the variable stays the same; only the contents change.

</details>

**3. True or false:** A variable can be updated more than once during a program.

<details>
<summary>Answer</summary>

**True**: Variables can be reassigned as many times as needed while the program runs.

</details>
