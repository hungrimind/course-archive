# Naming Variables

The label on your box matters. A box labeled *playerScore* tells you exactly what's inside. A box labeled *x* tells you nothing.

Good names are like labels on moving boxes: *kitchen utensils* beats *stuff #3*. When you come back to your code weeks later, clear names let you understand what's happening without guessing.
