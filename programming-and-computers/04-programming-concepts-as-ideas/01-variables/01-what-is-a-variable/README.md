# What is a Variable?

A **variable** is a labeled box that holds a value. One box might be labeled *score* and contain the number 42. Another might be labeled *username* and contain "Alice."

You can peek inside a box to read its value, swap the contents for something new, or hand the box to another part of your program. The label stays the same; it's just a name that points to whatever is currently inside.

## Fill in the Blanks

Fill in the blanks:

```typescript
let playerName = "Alice";
let playerScore = __(1)__;

console.log(__(2)__, "has score", __(3)__);
```

<details>
<summary>Answer</summary>

1. `100`
2. `playerName`
3. `playerScore`

</details>
