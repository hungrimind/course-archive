# Why Loops Exist

Imagine sending a "Happy New Year" message to 1,000 contacts. You wouldn't write the send instruction 1,000 times.

A **loop** lets you write an instruction once and say *repeat this*. It's the computer's version of "do this again", and the computer never gets bored, never skips one, and never makes a typo on attempt #847.

## Quiz

**1. What does a loop let you do?**

- A) Store a single value that never changes
- B) Write an instruction once and repeat it many times
- C) Give a name to a block of code you can call later
- D) Compare two values to see which is bigger

<details>
<summary>Answer</summary>

- B) Write an instruction once and repeat it many times

A loop lets you write one instruction and tell the computer to repeat it. This saves you from typing the same line over and over again.

</details>

**2. Why would a loop be a better choice than writing the same line 1,000 times?**

- A) The loop lets the computer skip some lines to save time
- B) It prevents typos and never gets bored or skips any repetition
- C) Loops are the only way to use numbers in a program
- D) Loops automatically make your code prettier on screen

<details>
<summary>Answer</summary>

- B) It prevents typos and never gets bored or skips any repetition

Computers running loops never get tired, never skip, and never make typos even on the 847th repetition. That reliability is why loops beat copy-pasting instructions.

</details>
