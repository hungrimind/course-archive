# Conditional Loops

A **conditional loop** keeps running until something changes. *Keep asking for a password until the user gets it right.*

You don't know in advance how many tries it will take; it depends on what happens while the loop is running. There's a catch: if the exit condition is never met, the loop runs forever. That's called an **infinite loop**, and it's one of the most common beginner mistakes.

## True or False

**1. True or false:** A conditional loop always knows exactly how many times it will repeat before starting.

<details>
<summary>Answer</summary>

**False**: A conditional loop keeps running until a condition changes, so the number of repetitions is unknown in advance.

</details>

**2. True or false:** If the exit condition of a conditional loop is never met, the loop runs forever.

<details>
<summary>Answer</summary>

**True**: This is called an infinite loop. The program gets stuck repeating endlessly because nothing tells it to stop.

</details>

**3. True or false:** A game that keeps asking 'play again?' until the player says no is an example of a conditional loop.

<details>
<summary>Answer</summary>

**True**: The loop continues based on the player's answer, not a preset count. It stops only when the condition changes.

</details>
