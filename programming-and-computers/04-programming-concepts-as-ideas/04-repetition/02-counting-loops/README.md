# Counting Loops

A **counting loop** repeats a set number of times. *Do this 10 times. For each song in the playlist, show the title.*

You know upfront how many repetitions there will be. The loop keeps a counter, does the work, ticks the counter forward, and stops when it's done, like checking off items on a numbered list.

## Fill in the Blanks

Fill in the blanks:

```typescript
// Print "Hello" 3 times
__(1)__ (let i = 0; i < __(2)__; i++) {
  console.log("Hello");
}
```

<details>
<summary>Answer</summary>

1. `for`
2. `3`

</details>
