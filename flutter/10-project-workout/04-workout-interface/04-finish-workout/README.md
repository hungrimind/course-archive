# Finish Workout

Lastly, we need to add a button to finish the workout.

## Assignment

Add a button to the left of the logout to finish the workout.

The workout should be saved to the database when the user clicks the button.

### Requirements

1. `TextButton` to the left of the logout button with the `Finish Workout` text that triggers the `finishWorkout` method.
