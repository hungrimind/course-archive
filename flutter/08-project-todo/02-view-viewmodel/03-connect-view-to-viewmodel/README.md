# Connect View to ViewModel

The UI structure is complete; the next step is connecting to the ViewModel to add our todos.

## Assignment

Remove the array of todos provided in the previous challenge and reimplement using the todos from the ViewModel.

### Requirements

1. Use the todos from the ViewModel to populate the UI.
2. Trigger the `add`, `remove`, and `toggleDone` functions when the corresponding buttons are pressed.
3. The todo list should reactively update when the todos change.
