# Hide Completed Todos

This last challenge is to add a button to the `AppBar` that toggles between showing all todos or only those that aren’t completed.

## Assignment

Add a button to the `AppBar` that toggles between showing all todos or only those that aren’t completed.

### Requirements

1. Add a button to the `AppBar` that toggles between “Show Done” and “Hide Done”.
2. When clicking, the list of todos should show all todos or only those that aren’t completed.
