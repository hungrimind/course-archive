# Local Styling

Local styling is what we have been doing so far. It is the styling that is applied to a single widget.

Here is a list of the most common types of styling:

1. Text Styling
2. Background and Foreground
3. Size and Spacing
4. Border and Decoration
5. Typography Alignment
6. Button Styling
7. Icons Styling
8. Animation Styling
9. Box and Clip Styling
10. Gradients
11. List and Grid Styling
12. Image Styling
13. Flex and Layout Alignment
14. Custom Themes
15. Opacity and Transformations
16. Interactive States

## Quiz

- A) Text Styling
- B) Global Theme Configuration
- C) Border and Decoration
- D) Size and Spacing
