# Tab Bar View

Now we need the `TabBar` to actually show the content for each tab.

## Assignment

Add a `TabBarView` with 3 children in the body of the `Scaffold` widget.

### Requirements

1. When you click on the `TabBar` it should show the corresponding `TabBarView`.
2. The `TabBarView` should have 3 children `Text` widgets with the text "For You Tab", "Following Tab", and "Subscribed Tab".
