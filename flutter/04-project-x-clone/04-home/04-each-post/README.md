# Each Post

We will be working within the "For You" tab to actually show the posts.

## Assignment

Instead of showing the "For You" text in the first tab, display a list of the posts.

### Requirements

1. Use a `ListView.builder` because we want the list to be dynamic.
2. Create a new Stateless widget called `PostEntry` that takes a `Post` as a parameter.
3. Display the `post.content` in a `Text` widget.

Code: [starter code](code/initial) · [solution](code/solution)
