# Update Counter

The default Flutter counter app is great at showing some of the basics of Flutter. An essential part of this starter app is that the number will increase when you tap the increment button.

This is because the `onPressed` property is set to a function that uses the `setState` method to update the state of the application.

We will learn more about this, but let's focus on the value that increments.

> Remember, if you want to test your code before you click the `Complete` button, you can click the `Hot Restart` button to see your updated app (make sure to toggle the preview).

## Assignment

Your task is to increment the value by 10 instead of 1.

Requirements:

- Every time you tap on the increment button, the value should increase by 10
