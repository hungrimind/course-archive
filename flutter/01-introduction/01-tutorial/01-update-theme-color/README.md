# Update Theme Color

Click the `Preview` button to see the application - it's the starter code for every Flutter application. It's a simple counter; you click the `+` to increase the number.

It defaults to this purple color, and we will learn how to change it in this lesson.

### Theme

The colors are associated with the app `theme`. There might be a lot of code you don't understand, but for now, let's focus on lines 13 and 14. On line 13 we define our theme using a `ThemeData` widget. Within that widget, we define a `colorScheme` for our application based on a _Deep Purple_ color.

There is a lot to look for in this small application, but right now, we are going to focus on just the `theme` color.

## Assignment

Your task is to change the theme color of the application from `Colors.deepPurple` to `Colors.blue`.

Requirements:

- Update the `seedColor` color of the theme to `Colors.blue`

## How to run the code

After you have completed the requirement above, try `Hot Restart` to see your changes reflected in the app. If you are happy with your solution, you can hit `Complete` to verify it.
