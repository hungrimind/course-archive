# Benefits of LSP

When adhered to, the **Liskov Substitution Principle (LSP)** ensures that derived classes can be used interchangeably with their base classes without altering the correctness of the program.

The main benefit of LSP is improved **reusability**. By designing classes that follow LSP, you make your codebase more flexible and easier to maintain. It also enhances **polymorphism**, allowing objects to be treated as instances of their parent class without concern for unexpected behavior.

> [!tip]
> If you can replace a base class with a derived class without changing the program's behavior, you're likely adhering to LSP.
