# Accessing Items

Each item in an array has a position called an **index**, starting from 0. You read an item by putting its index in square brackets after the array name.

```typescript
const colors = ["red", "green", "blue"];
console.log(colors[0]); // "red"
console.log(colors[1]); // "green"
console.log(colors[2]); // "blue"
```

The first item is always at index 0, not 1. This is called **zero-based indexing**.
