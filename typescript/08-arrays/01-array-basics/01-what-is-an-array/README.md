# What is an Array?

An **array** is an ordered list of values stored in a single variable. Instead of creating separate variables for each item, you group them together inside square brackets.

```typescript
const colors = ["red", "green", "blue"];
const scores = [95, 82, 74, 100];
```

Arrays can hold as many items as you need, and every item sits at a numbered position starting from 0.

## Quiz

**1. What index does the first item in an array have?**

- A) 0
- B) 1
- C) -1
- D) It depends on the array

<details>
<summary>Answer</summary>

- A) 0

Arrays use zero-based indexing, so the first item is always at index 0.

</details>

**2. Which of the following correctly creates an array in TypeScript?**

- A) const items = (1, 2, 3);
- B) const items = [1, 2, 3];
- C) const items = {1, 2, 3};
- D) const items = <1, 2, 3>;

<details>
<summary>Answer</summary>

- B) const items = [1, 2, 3];

Arrays are created using square brackets [] with comma-separated values inside.

</details>
