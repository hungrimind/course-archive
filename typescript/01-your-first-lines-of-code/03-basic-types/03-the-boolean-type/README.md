# The boolean Type

A **boolean** is either `true` or `false`, nothing else. It represents a yes/no decision.

```typescript
const isLoggedIn = true;
const hasPermission = false;
```

Booleans become essential once your code needs to make choices. Every "if this, then that" decision runs on them.

## Fill in the Blanks

Fill in the blanks:

```typescript
const isLoggedIn: boolean = __(1)__;
const hasPermission: __(2)__ = false;
```

<details>
<summary>Answer</summary>

1. `true`
2. `boolean`

</details>
