# The number Type

The **`number`** type covers both whole numbers and decimals. There's no separate "integer" or "float" type. It's all just `number`.

```typescript
const age = 30;
const price = 9.99;
const negative = -5;
```

## Fill in the Blanks

Fill in the blanks:

```typescript
const wholeNumber: __(1)__ = 42;
const decimal: __(2)__ = 9.99;
```

<details>
<summary>Answer</summary>

1. `number`
2. `number`

</details>
