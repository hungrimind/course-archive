# Printing Text

Text in programming is called a **string**. You wrap it in quotes, either double `"` or single `'`. Both work.

```typescript
console.log("Welcome to TypeScript");
console.log('Single quotes work too');
```

The quotes tell TypeScript "this is text, not code."


## Assignment

Use `console.log` to print two lines of text. The first line should print `I love coding` using double quotes, and the second line should print `TypeScript is fun` using single quotes.

Expected output:
```
I love coding
TypeScript is fun
```
