# Hello World

**console.log** is how you print things in TypeScript. Whatever you put inside the parentheses shows up on screen.

```typescript
console.log("Hello, world!");
```

That's it. One line, and you've got a working program.


## Assignment

Use `console.log` to print `"Hello, world!"` to the screen. Make sure the text matches exactly, including the comma and exclamation mark.
