# Multiple Prints

Each console.log prints on its own line. They run **top to bottom**, in the order you write them.

```typescript
console.log("First");
console.log("Second");
console.log("Third");
```

The output here is three separate lines: First, Second, Third. Order matters.


## Assignment

Write three `console.log` statements that print `"First"`, `"Second"`, and `"Third"` on separate lines, in that exact order.

## Challenge

Write three `console.log` statements that print `"First"`, `"Second"`, and `"Third"` on separate lines, in that exact order.
