# What is a Variable?

A **variable** is a named container that holds a value. You create one with the **`let`** keyword, give it a name, and use **`=`** to assign a value.

```typescript
let score = 10;
let greeting = "hello";
```

That's it. You now have two pieces of data you can refer to by name anywhere in your code.
