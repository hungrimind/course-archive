# Changing Values

Variables created with `let` can be **reassigned** at any time. Just use `=` again with the new value.

```typescript
let score = 0;
score = 10;
score = 25;
```

The old value is gone the moment you assign a new one. This is one of the most common things you'll do, updating stored information as your program runs.


## Assignment

The variable `score` starts at `0`. Reassign it to `10` before the second print, then reassign it to `25` before the third print. The output should be three lines: `0`, `10`, `25`.
