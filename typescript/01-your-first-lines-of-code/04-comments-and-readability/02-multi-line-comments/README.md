# Multi-Line Comments

For longer notes, wrap text between `/*` and `*/`. Everything in between is ignored.

```typescript
/*
  Price is calculated before discount.
  Discount logic lives in applyDiscount().
*/
const price = 49.99;
```

These are also handy for temporarily disabling a chunk of code while debugging.

## Fill in the Blanks

Fill in the blanks:

```typescript
__(1)__
  Price is calculated before discount.
  Discount logic lives in applyDiscount().
__(2)__
const price = 49.99;
```

<details>
<summary>Answer</summary>

1. `/*`
2. `*/`

</details>
