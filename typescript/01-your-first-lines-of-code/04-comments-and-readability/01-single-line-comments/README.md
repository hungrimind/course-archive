# Single-Line Comments

A **comment** starts with `//` and is completely ignored by TypeScript. Everything after `//` on that line is just a note for humans.

```typescript
const taxRate = 0.25; // 25% sales tax
```

Use them to explain *why* something exists, not *what* it does. The code already shows the "what."

## Fill in the Blanks

Fill in the blanks:

```typescript
const taxRate = 0.25; __(1)__ 25% sales tax
const maxRetries = 3; __(2)__ limit to avoid infinite loops
```

<details>
<summary>Answer</summary>

1. `//`
2. `//`

</details>
