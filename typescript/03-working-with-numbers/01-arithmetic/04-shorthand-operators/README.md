# Shorthand Operators

Instead of `count = count + 1`, write **`count += 1`**. Every arithmetic operator has a shorthand: **`+=`**, **`-=`**, **`*=`**, **`/=`**.

```typescript
let score = 10;
score += 5;  // 15
score -= 3;  // 12
score *= 2;  // 24
```

For adding or subtracting exactly 1, there's an even shorter form: **`score++`** and **`score--`**.

## Fill in the Blanks

Fill in the blanks:

```typescript
let score = 10;
score __(1)__ 5;
score __(2)__ 3;
score __(3)__ 2;
```

<details>
<summary>Answer</summary>

1. `+=`
2. `-=`
3. `*=`

</details>
