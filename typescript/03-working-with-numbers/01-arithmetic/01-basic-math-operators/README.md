# Basic Math Operators

TypeScript handles arithmetic with four operators: **`+`** for addition, **`-`** for subtraction, **`*`** for multiplication, and **`/`** for division.

```typescript
const price = 10 + 5;    // 15
const change = 20 - 7;   // 13
const total = 3 * 4;     // 12
const split = 100 / 4;   // 25
```

Division returns decimals when the numbers don't divide evenly. `7 / 2` gives you `3.5`, not `3`.


## Assignment

Implement four functions: `add`, `subtract`, `multiply`, and `divide`. Each takes two numbers and returns the result of the corresponding arithmetic operation. Remember that division returns decimals when numbers don't divide evenly.
