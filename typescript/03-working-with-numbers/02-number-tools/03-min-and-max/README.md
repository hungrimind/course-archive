# Min and Max

**`Math.min()`** returns the smallest number from its arguments, and **`Math.max()`** returns the largest. Pass as many numbers as you need.

```typescript
Math.max(3, 7, 2); // 7
Math.min(3, 7, 2); // 2
```

These are handy for clamping values, like making sure a health bar never drops below 0 or goes above 100.


## Assignment

Implement three functions. `getMin` and `getMax` each take three numbers and return the smallest or largest using `Math.min()` and `Math.max()`. `clamp` takes a value, a min, and a max, and returns the value constrained within that range.
