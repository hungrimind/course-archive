# Rounding Numbers

**`Math.round()`** rounds to the nearest whole number. **`Math.floor()`** always rounds down. **`Math.ceil()`** always rounds up.

```typescript
Math.round(4.5); // 5
Math.floor(4.9); // 4
Math.ceil(4.1);  // 5
```

`Math.floor()` is the one you'll reach for most, especially when you need a clean integer from a division or random number.
