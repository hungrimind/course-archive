# The if Statement

An **`if` statement** runs a block of code only when its condition is `true`. If the condition is `false`, the code inside the braces is skipped entirely.

```typescript
const temperature: number = 35;

if (temperature > 30) {
  console.log("It's hot outside!");
}
```

Condition goes in parentheses, code goes in curly braces. That's the whole pattern.
