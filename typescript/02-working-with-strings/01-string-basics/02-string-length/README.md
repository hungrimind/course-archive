# String Length

Every string has a **`.length`** property that returns the number of characters it contains, spaces and punctuation included.

```typescript
const message = "Hi there!";
console.log(message.length); // 9
```

It's a **property**, not a method, so you don't use parentheses. Just `.length`, no `()`.

## Fill in the Blanks

Fill in the blanks:

```typescript
const message = "Hi there!";
console.log(message.__(1)__); // 9
```
