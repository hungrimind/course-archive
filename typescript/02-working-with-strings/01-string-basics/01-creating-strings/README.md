# Creating Strings

Strings in TypeScript can be wrapped in **single quotes**, **double quotes**, or **backticks**. All three produce a string, so pick whichever your team prefers for consistency.

```typescript
const single = 'hello';
const double = "hello";
const backtick = `hello`;
```

Backticks look the same here, but they unlock special powers like embedding variables and writing multi-line text. More on that soon.
