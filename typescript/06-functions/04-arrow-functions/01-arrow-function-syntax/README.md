# Arrow Function Syntax

**Arrow functions** are a shorter way to write functions. Instead of the `function` keyword, you assign a function expression to a variable using `=>`.

```typescript
const add = (a, b) => {
  return a + b;
};

console.log(add(3, 5)); // 8
```

The behavior is the same as a regular function. The syntax is just more compact, and you'll see arrow functions everywhere in modern TypeScript.
