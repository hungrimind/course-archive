# Calling a Function

**Calling** a function runs the code inside it. Write the function's name followed by parentheses.

```typescript
function greet() {
  console.log("Hello there!");
}

greet(); // Hello there!
greet(); // Hello there!
```

Each call executes the entire function body from top to bottom. You can call the same function as many times as you want. That's the whole point of having one.
