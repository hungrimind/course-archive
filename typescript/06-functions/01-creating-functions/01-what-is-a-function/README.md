# What is a Function?

A **function** is a reusable block of code you give a name to. Instead of writing the same logic over and over, you define it once as a function and run it whenever you need it.

Think of a function like a recipe. You write the steps once, and every time you want to make the dish, you just follow the same recipe. Your program works the same way: one definition, unlimited uses.

## Quiz

**1. What is the main benefit of using a function?**

- A) It makes your code run faster
- B) You can define logic once and reuse it multiple times
- C) It prevents all errors in your program
- D) It automatically stores data in a database

<details>
<summary>Answer</summary>

- B) You can define logic once and reuse it multiple times

Functions let you define a block of code once and call it whenever you need it, avoiding repetition and making your code easier to maintain.

</details>

**2. Which analogy best describes how a function works?**

- A) A bookmark that saves your place in a book
- B) A recipe you write once and follow whenever you want to make the dish
- C) A calculator that only works once
- D) A lock that keeps code from running

<details>
<summary>Answer</summary>

- B) A recipe you write once and follow whenever you want to make the dish

A function is like a recipe: you write the instructions once, and you can follow them (call the function) as many times as you need.

</details>
