# Defining a Function

The **function** keyword creates a new function. Follow it with a name, parentheses, and curly braces. The code inside the braces is the **function body**. It doesn't run until you call the function.

```typescript
function greet() {
  console.log("Hello there!");
  console.log("Welcome aboard.");
}
```

The function exists now, but nothing has printed yet. Defining a function just stores the instructions for later.
