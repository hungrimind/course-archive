# Identifying Repeated Actions

Repeated actions in code often indicate a need for a loop. Look for tasks performed multiple times with slight variations.

```dart
print('Hello, Alice!');
print('Hello, Bob!');
print('Hello, Charlie!');
```

Here, the action of printing is repeated for each name. This is a candidate for a loop, which can execute a block of code multiple times with different inputs.

## Quiz

**1. What does the repetition of `print` statements in the given code suggest about the structure of the code?**

- A) It suggests the code is optimized and efficient.
- B) It suggests that a loop might be a better solution to handle repeated actions.
- C) It suggests that more print statements are needed.
- D) It suggests that the code cannot be improved.

<details>
<summary>Answer</summary>

- B) It suggests that a loop might be a better solution to handle repeated actions.

</details>

**2. Which of the following would best implement a loop for the greeting task?**

- A) Use a for loop to iterate over an array of names and print greetings.
- B) Add conditional statements to decide which greeting to print.
- C) Write a separate print statement for each name.
- D) Use a switch statement to handle each name's greeting.

<details>
<summary>Answer</summary>

- A) Use a for loop to iterate over an array of names and print greetings.

</details>

**3. What is an advantage of transforming repeated code into a loop?**

- A) It makes the code less readable.
- B) It increases the potential for bugs.
- C) It reduces code duplication and enhances maintainability.
- D) It has no impact on code quality.

<details>
<summary>Answer</summary>

- C) It reduces code duplication and enhances maintainability.

</details>
