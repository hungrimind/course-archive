# Creating a Constant

A **constant** is a variable whose value cannot change after it's set. In TypeScript, use the `const` keyword to declare a constant, ensuring a *single source of truth*. This aligns with D.R.Y. by preventing accidental changes and reducing repetition.

```typescript
const PI = 3.14159;
```

Here, `PI` is a constant, providing a consistent value across your code. This reduces the need to duplicate the value where used. 

> [!tip]
> Use constants for values that remain unchanged, like configuration settings or fixed calculations.
