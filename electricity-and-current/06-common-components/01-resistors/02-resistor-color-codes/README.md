# Resistor Color Codes

Resistors are too small for printed numbers, so they use **colored bands** to encode their value. Each color represents a digit: black is 0, brown is 1, red is 2, and so on up to white for 9.

The first two bands are digits, and the third band is a **multiplier** -- the number of zeros to add. So brown-black-red reads as 1-0-x100, which equals **1,000 ohms**.

> [!tip] You don't need to memorize the colors. A quick reference chart or an online calculator does the job perfectly.
