# What Fuses Do

A **fuse** is a deliberate weak point in your circuit. Inside it is a thin wire designed to melt and break the connection if too much current flows through.

It sacrifices itself so everything else survives. Think of it as a bodyguard -- once it takes the hit, it's done, and you need to replace it. That's a small price compared to replacing an entire circuit board or dealing with an electrical fire.

## Quiz

**1. What happens inside a fuse when too much current flows through it?**

- A) It redirects the current to ground
- B) A thin wire inside melts and breaks the connection
- C) It increases resistance to slow the current down
- D) It stores the excess energy for later use

<details>
<summary>Answer</summary>

- B) A thin wire inside melts and breaks the connection

A fuse contains a thin wire designed to melt when excessive current flows, breaking the circuit to protect other components.

</details>

**2. Why is a fuse described as a 'deliberate weak point' in a circuit?**

- A) Because it is the cheapest component
- B) Because it is designed to fail first so everything else survives
- C) Because it is always the smallest component
- D) Because it is optional and not really needed

<details>
<summary>Answer</summary>

- B) Because it is designed to fail first so everything else survives

A fuse is intentionally the weakest link in the circuit. It sacrifices itself by breaking when current is too high, protecting all the other more valuable components.

</details>
