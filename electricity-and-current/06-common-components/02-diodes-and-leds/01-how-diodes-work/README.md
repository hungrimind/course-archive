# How Diodes Work

A **diode** is a one-way valve for electricity. Current flows through it in one direction and gets blocked in the other.

This simple behavior is surprisingly useful. Diodes convert **AC to DC** by letting only one direction of the alternating current pass through. They also protect circuits from accidental reverse connections -- if you plug a battery in backwards, the diode blocks the current before it can do any damage.

## True or False

**1. True or false:** A diode allows current to flow in both directions equally.

<details>
<summary>Answer</summary>

**False**: A diode acts as a one-way valve, allowing current to flow in only one direction and blocking it in the other.

</details>

**2. True or false:** Diodes can be used to convert AC (alternating current) to DC (direct current).

<details>
<summary>Answer</summary>

**True**: By letting only one direction of alternating current pass through, diodes can convert AC to DC.

</details>

**3. True or false:** Diodes can protect circuits from accidental reverse connections.

<details>
<summary>Answer</summary>

**True**: Because diodes block current in one direction, they can prevent damage when a power source is accidentally connected backwards.

</details>
