# Current Electricity

**Current electricity** is a continuous flow of electrons through a conductor: not a one-time zap, but a steady stream. This is the kind of electricity that powers everything in your home.

Where static electricity is a sudden burst that's over in an instant, current electricity keeps flowing as long as there's a push (like a battery) and a path (like a wire) to flow through.

## Fill in the Blanks

Fill in the blanks:

```
Imagine a water park: a pump keeps water moving through a slide in a loop. In the same way, a __(1)__ provides the push, and a __(2)__ provides the path, creating a steady stream called __(3)__ electricity.
```

<details>
<summary>Answer</summary>

1. `battery`
2. `wire`
3. `current`

</details>
