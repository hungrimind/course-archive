# AC Frequency

**Frequency** is how many times per second AC completes a full back-and-forth cycle, measured in **hertz (Hz)**. North America uses 60 Hz; most of the rest of the world uses 50 Hz.

Here is the twist: each cycle has *two* direction changes (one forward, one back). So 60 Hz means the current actually reverses 120 times per second. It is so fast that a light bulb on AC looks perfectly steady to your eyes.

## Fill in the Blanks

Fill in the blanks:

```
A European appliance operates at __(1)__ Hz. Each cycle has two direction changes, so the current reverses __(2)__ times per second. The unit used to measure this frequency is called __(3)__.
```

<details>
<summary>Answer</summary>

1. `50`
2. `100`
3. `hertz`

</details>
