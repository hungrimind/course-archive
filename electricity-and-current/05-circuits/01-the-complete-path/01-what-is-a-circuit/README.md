# What Is a Circuit?

A **circuit** is a complete loop that electricity can travel through. Current leaves the power source, flows through wires and components, and returns to where it started.

If the loop is broken *anywhere*, current stops everywhere. No complete path, no flow -- it's that simple.

## Exercise: Build the Circuit

Build the simplest possible circuit: connect the battery, resistor, and LED in a complete loop. The resistor protects the LED by limiting current to a safe level (9.1mA).

Available components: 5V Battery, 330Ω Resistor, Green LED

<details>
<summary>Solution</summary>

Wires:

- 5V Battery (+) → 330Ω Resistor (in)
- 330Ω Resistor (out) → Green LED (anode)
- Green LED (cathode) → 5V Battery (-)

</details>
