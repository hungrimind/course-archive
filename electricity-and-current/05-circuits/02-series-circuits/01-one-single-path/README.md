# One Single Path

In a **series circuit**, every component is connected end-to-end in a single loop -- like beads on a string. The same current flows through each one in turn.

The catch? If *any* component fails, the entire circuit breaks. Old-style Christmas lights worked this way -- one dead bulb and the whole string went dark.

## Exercise: Build the Circuit

Wire two red LEDs in series with the resistor and battery — all in one single loop. Each LED drops 2V, and the 270Ω resistor keeps current at a safe 18.5mA.

Available components: 9V Battery, 270Ω Resistor, Red LED, Red LED

<details>
<summary>Solution</summary>

Wires:

- 9V Battery (+) → 270Ω Resistor (in)
- 270Ω Resistor (out) → Red LED (anode)
- Red LED (cathode) → Red LED (anode)
- Red LED (cathode) → 9V Battery (-)

</details>
