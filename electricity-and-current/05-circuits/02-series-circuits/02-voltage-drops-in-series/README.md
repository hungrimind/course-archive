# Voltage Drops in Series

Each component in a series circuit uses up a share of the total voltage. These individual **voltage drops** always add up to match the source.

A 9V battery powering three identical LEDs? Each one gets about 3V. Add a fourth and each gets less. The battery's voltage is a fixed budget, and every component in the series takes its cut.

## Quiz

**1. A 9V battery powers three identical LEDs in series. Approximately how much voltage does each LED receive?**

- A) 9V each
- B) 6V each
- C) 3V each
- D) 1V each

<details>
<summary>Answer</summary>

- C) 3V each

In a series circuit, the total voltage is divided among the components. With three identical LEDs sharing a 9V supply, each gets about 3V (9V / 3 = 3V).

</details>

**2. What happens to the voltage per component if you add a fourth identical LED to a series circuit with a fixed battery?**

- A) Each LED gets more voltage because there are more components
- B) Each LED gets less voltage because the battery's voltage is shared among more components
- C) The voltage stays the same for each LED
- D) The battery automatically increases its voltage output

<details>
<summary>Answer</summary>

- B) Each LED gets less voltage because the battery's voltage is shared among more components

The battery's voltage is a fixed budget. Adding more components in series means each one gets a smaller share of the total voltage.

</details>
