# Series vs Parallel

**Series** circuits have one path -- the same current everywhere, voltage shared across components. **Parallel** circuits have multiple paths -- full voltage on each branch, current shared across them.

Most real devices use *both*. Your phone's circuit board has components wired in series within branches that run in parallel. Understanding the difference is the key to reading how any circuit actually works.
