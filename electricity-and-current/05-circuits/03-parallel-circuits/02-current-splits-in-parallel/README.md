# Current Splits in Parallel

In a parallel circuit, the total current from the source **splits** among the available branches. Each path draws whatever current its resistance allows -- a low-resistance branch pulls more, a high-resistance branch pulls less.

Add more branches and the *total* current from the source goes up. That's why plugging too many appliances into one outlet can trip a breaker -- each new path demands more current.

## Quiz

**1. In a parallel circuit, which branch draws the most current?**

- A) The branch closest to the power source
- B) The branch with the highest resistance
- C) The branch with the lowest resistance
- D) All branches always draw equal current

<details>
<summary>Answer</summary>

- C) The branch with the lowest resistance

Each branch draws current according to its resistance. A low-resistance branch allows more current to flow, while a high-resistance branch restricts it.

</details>

**2. Why can plugging too many appliances into one outlet trip a circuit breaker?**

- A) Each new appliance reduces the total voltage
- B) Each new parallel branch demands more current from the source, eventually exceeding the breaker's limit
- C) The appliances create a short circuit
- D) The outlet runs out of electrons to supply

<details>
<summary>Answer</summary>

- B) Each new parallel branch demands more current from the source, eventually exceeding the breaker's limit

Each new appliance adds another parallel branch, increasing the total current drawn from the source. When that total exceeds the breaker's rated limit, it trips to protect the wiring.

</details>
