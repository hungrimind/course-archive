# Analog Signals Explained

An **analog signal** varies smoothly and continuously, so it can be *any* value within a range. Think of a dimmer switch: you can set the light to any brightness, not just "on" or "off."

The voltage might be 2.3V, then 2.31V, then 2.317V. There are infinite possible positions between any two points. The signal flows like a smooth curve, never jumping in steps.

## True or False

**1. True or false:** An analog signal can only take whole-number voltage values like 1V, 2V, or 3V.

<details>
<summary>Answer</summary>

**False**: An analog signal varies smoothly and continuously, so it can take any value within a range, including 2.3V, 2.31V, or 2.317V. There are infinite possible values, not just whole numbers.

</details>

**2. True or false:** A dimmer switch is a good analogy for an analog signal because it allows any brightness level, not just on or off.

<details>
<summary>Answer</summary>

**True**: A dimmer switch lets you set the light to any brightness between fully off and fully on, just like an analog signal can take any voltage value within its range, smoothly and continuously.

</details>

**3. True or false:** An analog signal moves in discrete steps, jumping from one fixed level to the next.

<details>
<summary>Answer</summary>

**False**: An analog signal flows like a smooth curve, never jumping in steps. It transitions continuously between values with infinite possible positions between any two points.

</details>

**4. True or false:** Between any two points on an analog signal, there are infinite possible values.

<details>
<summary>Answer</summary>

**True**: Because an analog signal is continuous, you can always find a value between any two measurements. Between 2.3V and 2.4V there is 2.35V, between 2.3V and 2.35V there is 2.325V, and so on, infinitely.

</details>
