# How the Three Connect

Voltage, current, and resistance are locked together. Change one and you change the others.

More **voltage** pushes more current through. More **resistance** chokes the current down. **Current** is the result of the tug-of-war between the two: voltage pushing electrons forward, resistance holding them back.

> [!note] This relationship has a precise formula called **Ohm's Law**, which you'll learn in the next module.
