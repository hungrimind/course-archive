# Measuring Current

Current is measured in **amperes**, usually shortened to **amps (A)**. For small electronics, you'll see **milliamps (mA)**, one-thousandth of an amp.

An LED might use 20mA. Your phone charger draws about 1-2A. A toaster pulls 5-10A. The bigger the device, the more current it needs.
